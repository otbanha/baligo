# 巴厘岛最新新闻｜11月24日：暴雨造成20处灾情、沿海高潮警报与新航线恢复

巴厘岛雨季正式进入需要提高警惕的时期。11月22日晚间至23日凌晨的强降雨，已在全岛造成20处灾害事件，库塔、雷吉安及登巴萨部分道路出现淹水，另外还发生土石流及人员死亡事故。

除了天气，年底旅游交通也有新消息。Wings Air将于11月27日恢复Jember与巴厘岛之间的直飞航班，巴东则将在本周末举办大型创意经济节。

## 🌦️ 11月24日巴厘岛天气：多地仍有豪雨可能，南部海域浪高达2米

印尼气象、气候及地球物理局（BMKG）巴厘岛第三区气象中心公布11月24日最新天气预报，整体以小雨为主，但仍须留意部分地区可能出现中至大雨及雷电。

**11月24日全岛天气概况：**

| 项目 | 预报 |
| --- | --- |
| 天气 | 小雨，局部可能较强 |
| 气温 | 20–33°C |
| 相对湿度 | 70–95% |
| 风向 | 东南至西南风 |
| 风速 | 4–31公里/小时 |
| 北部海域浪高 | 0.5–1米 |
| 南部海域浪高 | 0.5–2米 |

BMKG提醒，巴厘岛大部分地区仍有中至大雨及雷电的可能，尤其山区、河川周边及容易积水的低洼地区，应留意突发性降雨。

**另外，还有一项容易被旅客忽略的警报：沿海高潮淹水（Rob）。**

BMKG第三区已发布11月23日至25日沿海高潮淹水预警。11月24日适逢满月及月球近地点（Perigee），可能使部分沿海地区的最高潮位增加。

六个可能受影响的县市及区域包括：

| 地区 | 可能受影响的沿海区域 |
| --- | --- |
| Badung巴东 | Kuta、Kuta Selatan、Kuta Utara、Mengwi |
| Gianyar吉安雅 | Blahbatuh、Gianyar、Sukawati |
| Jembrana珍布拉娜 | Jembrana、Melaya、Mendoyo、Negara、Pekutatan |
| Klungkung克隆孔 | Banjarangkan、Dawan、Klungkung、Nusa Penida |
| Denpasar登巴萨 | Denpasar Selatan、Denpasar Timur |
| Tabanan | Kediri、Kerambitan、Selemadeg、Selemadeg Barat、Selemadeg Timur、Tabanan |

这项警报不代表上述地区一定会发生淹水，也不代表海滩全面关闭，而是提醒沿海低洼地区、港口及海滩活动应留意潮汐变化。

**给旅客的提醒：**

- 住在Kuta、Seminyak、Sanur及Nusa Dua等沿海区域，可留意住宿周边是否有积水。
- 前往海滩拍照或散步时，注意潮位及海浪变化。
- 前往Nusa Penida的旅客，除了确认船班，也应留意码头及沿岸状况。
- 雨势较大时，避免安排瀑布、山区及河谷活动。

## 🚨 巴厘岛一夜暴雨造成20处灾情！库塔、雷吉安及登巴萨道路淹水

11月22日下午至23日凌晨，巴厘岛多地遭遇强降雨，根据巴厘岛省灾害管理局（BPBD）截至11月23日上午9时的统计，全岛共有20处灾害事件。

https://www.instagram.com/reel/DgD70siy50u/?utm_source=ig_web_copy_link&bqrl=NTc4MTIwNjQ2YQ==

降雨量相当惊人：

| 地区 | 24小时累积雨量 |
| --- | --- |
| Tampaksiring | 161毫米 |
| Karangasem | 149毫米 |
| Selemadeg Barat | 111毫米 |

其中Tampaksiring已达极端降雨等级。

20处灾害事件分布如下：

- 登巴萨：7处
- 巴东：4处
- 塔巴南：4处
- Jembrana：2处
- Karangasem：2处
- Bangli：1处

主要灾情包括道路淹水、树木倒塌、土石流及建筑物受损。

**对游客影响较直接的是Kuta及Legian。**

11月23日上午，Kuta及Legian部分道路出现积水，部分路段水深达成人小腿附近。Tukad Mati河道也因水量增加，出现大量塑料垃圾及木材卡在桥下的情况。

当地清洁人员及相关单位已投入清理，部分积水逐渐消退，但仍有地点需要抽水及清除障碍物。

另外，当晚及凌晨的豪雨也造成两起严重事故：

- Badung县Mengwi一名女童跌入排水沟，遭急流冲走，于11月23日下午寻获，已不幸身亡。
- Karangasem县Sidemen一名65岁女性遭土石流掩埋，救援人员于11月23日上午寻获遗体。

这两起事故都与强降雨有关，也显示雨季期间排水沟、河道及山坡周边的危险性。

**给旅客的提醒：**

如果明天准备从机场前往库塔、雷吉安或水明漾，建议出发前确认道路状况，并预留更多交通时间。

雨季在巴厘岛开车，最需要避免的不是下雨本身，而是低估积水、河水暴涨及山坡土石流的风险。遇到积水路段，不要冒险涉水通过。

## ✈️ Jember直飞巴厘岛航线11月27日恢复！Wings Air每周飞航两班

印尼东爪哇Jember与巴厘岛之间的直飞航班即将恢复，对计划结合东爪哇及巴厘岛旅行的旅客来说，是一项值得留意的交通消息。

根据Jember交通局11月23日公布的消息，Wings Air将从2026年11月27日起，重新营运Jember至巴厘岛的航线。

航班资料如下：

| 项目 | 资讯 |
| --- | --- |
| 航空公司 | Wings Air |
| 航线 | Jember（JBB）－Denpasar（DPS） |
| 开始日期 | 2026年11月27日 |
| 班次 | 每周一、周五 |
| 机型 | ATR 72-500／ATR 72-600 |
| 飞行时间 | 约1小时20分钟 |

参考时刻：

- 巴厘岛飞往Jember：08:05 WITA出发
- Jember飞往巴厘岛：09:00 WIB出发

目前公布的起始票价为：

- Jember → 巴厘岛：IDR 640,000起
- 巴厘岛 → Jember：IDR 761,000起

实际票价会依出发日期及座位供应而变动。

这条航线过去曾于2025年12月开通，但因航空燃油成本上升，于2026年5月暂停运营，这次配合圣诞节及新年假期重新启用。

对巴厘岛旅客而言，这也增加了安排东爪哇旅行的可能性。Jember周边可以延伸探索Papuma Beach、Watu Ulo Beach及周边自然景点。

如果已经在巴厘岛旅行，想顺道前往东爪哇，未来可以多一个不必长途搭乘汽车及渡轮的选择。

## 🏌️ Handara Golf & Resort连续两年获亚洲最佳环保高尔夫设施！Bedugul高原度假再受国际关注

位于巴厘岛Bedugul高原的Handara Golf & Resort Bali，再度获得World Golf Awards 2026的Asia's Best Eco-Friendly Golf Facility奖项，连续两年获得相同肯定。

这项奖项肯定度假村在环境保护及永续经营方面的努力，今年也恰逢Handara成立50周年。

Handara表示，目前推动的环保措施包括：

- 节约及管理水资源
- 减少垃圾及一次性塑料使用
- 推动Micro Farm及Farm to Table
- 使用在地农产品及供应商
- 加强与当地社区的合作

度假村也表示，约90%的员工及高尔夫球场球童来自周边地区，并与16家在地供应商合作。

Handara位于Bedugul高原，周边气候较凉爽，与巴厘岛南部海岸型度假村有明显不同。

对喜欢高尔夫、山区度假及自然环境的旅客来说，这项消息也让Handara再次受到国际旅游市场关注。

不过，这是设施及永续经营方面的产业奖项，并不等同于住宿品质排名或价格保证，实际预订仍应参考房型、设施及近期旅客评价。
