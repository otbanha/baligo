# **巴厘岛最新新闻｜11月25日：雨季暴雨警报、离岛快艇加强检查与外国人遣返**

巴厘岛雨季持续带来天气及交通方面的挑战。BMKG最新预报指出，11月25日部分地区仍有中到大雨及雷电可能，Bedugul、金塔马尼及Besakih等景点都需要留意天气变化。

另外，随着圣诞节及新年旅游旺季接近，巴厘岛警方开始加强海上交通安全检查，特别是往返努沙佩尼达的快艇。移民局也公布最新外国人遣返案件，而Sanur则有一场印度文化节正在举行。

## **🌧️ BMKG预警11月25日部分地区大雨！金塔马尼、Bedugul及Besakih留意雷雨**

印尼气象、气候及地球物理局（BMKG）巴厘岛第三区气象中心于11月24日发布最新预警，预测11月24日至27日期间，巴厘岛部分地区可能出现中到大雨，并伴随雷电。

**11月25日全岛天气概况：**

| 项目 | 预报 |
| --- | --- |
| 整体天气 | 小雨，局部可能较强 |
| 气温 | 20–33°C |
| 相对湿度 | 70–98% |
| 风向 | 东南至西南风 |
| 风速 | 4–30公里/小时 |
| 北部海域浪高 | 0.25–1米 |
| 南部海域浪高 | 0.5–2.5米 |

BMKG针对不同时段发布的降雨警戒：

- **11月25日至26日上午8时：** Badung、Bangli、Buleleng、Karangasem及Tabanan可能出现中等降雨。
- **11月26日至27日上午8时：** Badung、Buleleng及Tabanan进入大雨警戒，Bangli、Denpasar、Karangasem、Gianyar及Klungkung则需留意中等降雨。

另外，BMKG特别点名11月25日以下旅游地区可能出现降雨及雷电：

- Bedugul（贝都古）
- Kintamani（金塔马尼）
- Besakih（母庙）

**对旅客的影响：**

如果明天安排金塔马尼火山景观、Bedugul湖区或Besakih母庙，建议保留行程弹性，避免在雷雨期间进行山区户外活动。

南部海域浪高可能达2.5米，前往努沙佩尼达、努沙蓝梦岛的旅客，应在出发前确认快艇公司是否正常营运。

雨季并不代表整天都会下雨，但这几天不建议把瀑布、山区及海上活动排得太紧密。

## **🚤 巴厘岛警方部署4艘巡逻船！努沙佩尼达快艇加强安全检查**

随着圣诞节及2027年新年旅游旺季接近，巴厘岛警方海上警察单位（Ditpolairud Polda Bali）已启动港口整合安全巡逻，部署4艘巡逻船，加强巴厘岛各海上交通入口的管理。

根据11月24日Bali Post报道，警方特别关注巴东海峡（Selat Badung），包括沙努尔及Kusamba往返努沙佩尼达的快艇航线。

这次安全管理分为两个层面：

**港口检查**

警方与港务单位在各港口进行出航前检查，主要确认：

- 船上乘客人数与乘客名册是否一致。
- 是否有超载情况。
- 救生衣数量是否符合乘客人数。
- 灭火器及救生艇是否能正常使用。

如果船只设备不符合安全要求，将不允许出航。

**海上巡逻**

4艘巡逻船将加强容易发生事故的航线监控，尤其是往返努沙佩尼达的快艇，避免船只高速行驶、危险超车或切入大型船舶航道。

警方也将与BMKG、Basarnas印尼搜救单位及海军合作，根据天气与海况调整巡逻及安全管理。

**对旅客的影响：**

这项措施对搭乘Sanur至Nusa Penida、Kusamba至Nusa Penida快艇的旅客尤其重要。

建议：

- 选择有正式营运及安全设备的快艇业者。
- 不要为了赶时间选择超载船只。
- 出发前确认救生衣及安全设备。
- 雨季期间不要只依赖船公司原定时刻表，应确认当日是否正常出航。

这次加强检查并不代表离岛航线全面停驶，而是希望在年底旺季到来前，降低海上交通事故风险。

## **🛂 巴厘岛移民局再遣返5名外国人！包括逾期居留及持访问签证经营刺青店**

巴厘岛Denpasar移民拘留中心（Rudenim Denpasar）于11月24日公布，近期共遣返5名违反印尼移民规定的外国人，国籍包括俄罗斯、也门、印度及澳大利亚。

这批案件中，公开的违规情况包括：

| 国籍 | 违规情况 |
| --- | --- |
| 俄罗斯 | 逾期居留45天 |
| 印度 | 逾期居留187天 |
| 也门 | 逾期居留64天 |
| 澳大利亚 | 持访问签证在库塔经营刺青生意 |
| 澳大利亚 | 逾期居留787天，超过两年 |

其中，持访问签证在库塔经营刺青生意的澳大利亚籍人士，是这次案件中值得特别注意的案例。

移民局认为，持有访问签证不代表可以在巴厘岛从事未获许可的商业活动，因此依法执行遣返。

另一名澳大利亚籍人士逾期居留787天，时间已超过两年。

移民拘留中心负责人Teguh Mentalyadi表示，外国人在印尼必须遵守相同的移民规定，遣返程序须在完成行政手续及旅行文件准备后执行。

**给旅客及长期居留者的提醒：**

- VOA及eVOA必须在允许的停留期限内离境或依法延签。
- 访问签证不等于工作许可。
- 即使是在巴厘岛经营小型商业活动，也应确认适用的签证及工作许可。
- 如果计划长期居留，不要等到签证即将到期才处理延期。

一般观光客不需要因为这类案件过度担心，但签证期限与实际活动是否符合许可范围，确实是不能忽略的事情。
