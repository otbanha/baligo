# 印尼QRIS是什么？2026巴厘岛旅游「无现金支付」完全解析

到巴厘岛旅行，你一定会在路边摊、超市、按摩店，甚至海滩俱乐部的柜台上，看到一张印着彩色方块图案的小卡片，旁边写着「QRIS」。这其实是印尼全国统一的移动支付QR Code标准，也是这几年当地人消费习惯快速改变的关键。这篇文章就来完整说明QRIS是什么、台湾旅客能不能直接扫码付款，以及在巴厘岛实际可行的无现金支付方式。

![raw-image](https://images.gobaligo.id/images/2026-08/1786361369033-kjc6my8wmxwkk4flysvvmmknrmekbidltfkklf1y.png)

## QRIS到底是什么？

QRIS全名是「Quick Response Code Indonesian Standard」，由印尼央行（Bank Indonesia）在2019年推出，目的是统一境内原本各自为政的移动支付QR码。在QRIS出现以前，GoPay、OVO、DANA等电子钱包各有各的付款码，店家常常要贴出一整排QR码供不同用户扫描，非常混乱。QRIS上线后，商家只需要一组QR码，不管消费者用哪一款App，都能扫同一组码完成付款——概念上跟台湾现在推广的TWQR相当类似。

这个系统普及的速度相当惊人。根据印尼央行公布的数据，截至2026年第一季度，QRIS交易量年增率已经超过133%，光是巴厘岛当地使用QRIS的商家就超过110万家，用户数突破115万人。从路边的Nasi Goreng摊贩到连锁超市Indomaret、Alfamart，几乎都已经支持QRIS扫码付款。

## 台湾旅客能直接用手机扫QRIS付款吗？

这是很多人最想知道的问题，答案是：**目前还不行**。

印尼央行近年积极推动「QRIS跨境（QRIS Antarnegara / QRIS Cross-border）」计划，让部分国家的旅客可以直接用自己国家的移动支付App，扫描印尼当地的QRIS码付款，反之亦然。截至2026年中，已经正式开通的合作国家包括泰国、马来西亚、新加坡、日本、韩国与中国，印尼央行也正在与沙特阿拉伯、印度进行跨境QRIS的试点。

不过，台湾目前并不在这份合作名单之中，所以像LINE Pay、街口支付等台湾常用的移动支付App，暂时没办法直接扫描巴厘岛店家的QRIS码结账。想在巴厘岛用手机无现金消费，还是需要通过当地的电子钱包来完成。

## 巴厘岛实际可行：申办当地电子钱包

![raw-image](https://images.gobaligo.id/images/2026-08/1786361435327-2024_11_11_157146_1731331014._large.jpg)

▲QRIS除了可以在所有的超市、便利店使用，越来越多的商店，甚至是路边小贩都可以使用

好消息是，申办印尼本地电子钱包完全不难，用台湾手机号就能注册，而且几乎都能扫QRIS消费。目前最主流的三个选择是GoPay、DANA、OVO：

- **GoPay**：附属于超级App Gojek，除了付款，还能叫车、叫外卖，是外国游客最常用的入门选择，注册门槛也最低。不过要注意，GoPay目前不开放外国信用卡直接绑定充值，主要充值方式是到Indomaret、Alfamart等超市用现金充值，或请Gojek司机协助代充。部分教程也提到可用海外借记卡（Debit Card）免手续费充值，但实际能否成功因发卡银行而异，建议抵达后现场测试小额充值。
- **DANA**：对外国游客较友善的一点是，可以直接绑定Visa或万事达卡的外卡进行QRIS付款，不需要印尼当地身份证（KTP），流程相对简单。
- **OVO**：同样支持QRIS付款，但部分进阶功能有时需要当地身份验证，适合作为备用选项。

实务上，建议主力使用GoPay（因为叫车、外卖、付款一站式搞定），现金也保留一些小额，因为部分小型商家偶尔仍只收现金。

## 使用QRIS消费的基本流程

1. 打开电子钱包App（以GoPay为例）
2. 点击「扫描」或「Scan QR」功能
3. 对准店家桌上或收银台的QRIS码
4. 确认商家名称与金额无误后，输入密码或指纹完成付款
5. 屏幕出现付款成功画面即完成，不需签名或额外手续

![raw-image](https://images.gobaligo.id/images/2026-08/1786361812303-banner_news_qris_edc_fe1cee70f3.jpg)

QRIS付款没有最低金额限制，即使是台币一元的小额消费也能使用，这也是为什么连路边摊贩都愿意申请QRIS的原因。

## 使用QRIS时的注意事项

- **付款前务必核对商家名称**：QRIS码一般会显示收款商家名称，付款前先确认名称与眼前店家相符，避免扫到错误或伪造的QR码。
- **金额务必自行输入或核对**：多数QRIS为「动态码」，扫描后App会自动带出金额，但仍建议付款前再次确认金额是否正确。
- **保留付款成功画面**：偶尔网络不稳定会导致扣款状态不明，建议保留交易记录截图，方便日后对账。
- **App储值余额控管**：因为储值后余额多半绑定在App内，建议依当次旅程需求少量多次储值，避免账户内留存过多余额。

## 常见问题

**Q：一定要用印尼电子钱包才能消费吗，信用卡不能用吗？** 巴厘岛市区的饭店、餐厅、购物中心多半仍可直接刷卡（Visa／Mastercard），QRIS主要是解决小型商家、路边摊、传统市场这类过去只能收现金的消费场景，两种方式可以互相搭配使用。一般可以刷卡的商店一定可以使用QRIS；可以使用QRIS的商店不一定可以刷卡。

**Q：储值会被收手续费吗？** 超商现金储值一般会有小额手续费，实际费率依App与储值管道而异，储值前可在App内确认当下费用说明。

**Q：QRIS未来会开放台湾直接跨境支付吗？** 印尼央行的QRIS跨境合作名单仍在持续扩增中，近期陆续新增日本、韩国、中国，并试点沙特阿拉伯与印度，是否纳入台湾仍需留意官方后续公告。

## 结语

QRIS已经成为巴厘岛当地消费的主流方式，即使台湾旅客暂时无法直接用本地App跨境扫码付款，只要提前申办GoPay或DANA，搭配现金与信用卡三种方式交叉使用，就能在巴厘岛轻松应付从路边小吃到高级餐厅的各种消费场景，不必再担心身上现金不够或找零麻烦的问题。
