# 巴厘岛最新新闻｜11月26日：雨季天气、吉隆坡新航线与年底物价警戒

巴厘岛11月25日的旅游消息，除了雨季天气及海况提醒，航空交通也有新发展。TransNusa宣布12月起开通巴厘岛直飞吉隆坡航线，让旅客有更多东南亚转机及多国旅游选择。

另一方面，印尼央行开始警告年底假期可能带来物价上涨压力，巴厘岛移民局也公布一起涉及外国人的跨国假投资案件。

## 🌦️ 11月26日巴厘岛天气：中部及东部部分地区有雨，南部海域浪高约2.1米

印尼气象、气候及地球物理局（BMKG）11月25日更新巴厘岛各县市天气预报，11月26日全岛仍以多云及局部降雨为主。

**11月26日各地天气预测：**

| 地区 | 天气 | 气温 |
| --- | --- | --- |
| Denpasar登巴萨 | 小雨 | 25–31°C |
| Badung巴东 | 小雨 | 24–31°C |
| Gianyar吉安雅 | 中雨 | 23–30°C |
| Tabanan | 中雨 | 22–27°C |
| Bangli | 中雨 | 19–26°C |
| Klungkung克隆孔 | 小雨 | 26–32°C |
| Karangasem卡朗阿森 | 小雨 | 20–28°C |
| Buleleng布勒伦 | 多云 | 24–31°C |
| Jembrana珍布拉娜 | 小雨 | 22–29°C |

从预报来看，Tabanan、Gianyar及Bangli需要特别留意降雨，其他地区也不能完全排除午后降雨。

**海况方面：**

BMKG海洋气象预报显示，11月26日巴厘岛南部印度洋海域浪高约1.9至2.1米，属中等浪况；巴厘岛海域其他部分区域则约0.8至1.2米。

对旅客而言，最需要注意的是离岛及海上活动。

如果安排努沙佩尼达、努沙蓝梦岛或南部海岸水上活动，建议先向船公司确认当日海况及出航安排。

山区方面，前往乌布、金塔马尼及Bedugul，也建议保留行程弹性，尤其是瀑布、山路及户外活动。

目前没有全岛景点统一关闭的消息，实际状况仍应以当地最新天气及海况公告为准。

## ✈️ TransNusa开通巴厘岛直飞吉隆坡！12月10日起每周4班

巴厘岛与马来西亚之间即将增加一条直飞航线。

印尼航空公司TransNusa宣布，从2026年12月10日起，正式开通巴厘岛登巴萨（DPS）往返吉隆坡国际机场（KUL）的直飞航班。

这是TransNusa今年从巴厘岛出发的第三条国际航线，之前已陆续开通普吉岛及墨尔本航线。

**航班信息：**

| 项目 | 信息 |
| --- | --- |
| 航空公司 | TransNusa |
| 航线 | 巴厘岛DPS－吉隆坡KUL |
| 开航日期 | 2026年12月10日 |
| 每周班次 | 4班 |
| 飞行方式 | 直飞 |

**航班时间：**

| 航班 | 出发 | 抵达 |
| --- | --- | --- |
| 8B601 | 巴厘岛 11:00 | 吉隆坡 14:05 |
| 8B602 | 吉隆坡 14:40 | 巴厘岛 18:05 |

航班时间均为当地时间。

每周运营日为星期一、四、五及日。

TransNusa也表示，这条航线将提供单一机票预订及行李直挂服务，对从墨尔本、珀斯出发，经巴厘岛转往吉隆坡的旅客特别方便。

行李方面，航空公司公布的方案包括至少20公斤免费托运行李，以及7公斤手提行李。

**对台湾及其他华语市场旅客的影响：**

这条航线不只是增加巴厘岛与马来西亚之间的交通选择，也让安排印尼、马来西亚及澳洲多国旅游的旅客有更多组合。

如果原本计划在巴厘岛度假后前往吉隆坡，12月10日之后可以多比较TransNusa与其他航空公司的价格及时间。

订票前仍建议确认实际航班日期、票价、行李规定及是否符合转机条件。

## 💰 印尼央行警告年底物价上涨压力！圣诞新年加上2027年Galungan节庆

印尼央行巴厘岛代表处于11月25日提醒，巴厘岛年底至明年初可能面临较大的通胀压力。

主要原因是2026年圣诞节及新年假期（Nataru），接着又遇上2027年1月的Galungan及Kuningan传统节庆。

这几个时段的消费需求叠加，可能增加食品及日常用品的供应压力。

印尼央行巴厘岛代表Achris Sarwani指出，巴厘岛常住人口约450万至500万人，但来自巴厘岛以外的旅客流量可能接近2,000万人次，庞大的消费需求对当地物价管理构成挑战。

**目前几项值得注意的数字：**

| 项目 | 数据 |
| --- | --- |
| 2026年1至10月累积通胀率 | 2.74% |
| 通胀目标上限 | 3.5% |
| 剩余目标空间 | 0.76个百分点 |
| 已执行市场平价措施 | 约377次 |

央行也指出，部分食品的现有库存只能满足不到两周的需求，因此要求地方物价控制小组（TPID）加强市场供应及价格监控。

**最需要留意的期间：**

2026年12月10日至2027年1月31日，约7周。

这段时间除了圣诞节及新年旅游旺季，也会遇到巴厘岛重要的Galungan及Kuningan节庆，当地食品及家庭用品需求可能进一步增加。

**对旅客的影响：**

这项警告主要针对食品及民生用品供应，并不是官方宣布旅馆、机票或景点门票即将全面涨价。

不过，如果安排年底长住、租Villa自行料理，或经常在当地市场购买食材，可以多留意超市及市场价格。

另外，12月底至1月的旅游旺季，住宿与交通仍建议提早预订，不要等到最后一刻才安排。

## ⚠️ 巴厘岛移民局公布外国人假投资案件！20人涉嫌组成跨国诈骗网络

巴厘岛Ngurah Rai移民局11月25日公布，近期针对外国人违规活动展开一系列执法，当中有20名外国人涉嫌参与一个针对巴厘岛其他外国人的跨国假投资网络。

根据移民局负责人Muhammad Novyandri的说明，这20名外国人是在11月5日于南库塔（Kuta Selatan）Ungasan地区的一次联合行动中被查获。

这起案件被列入移民局11月16日至20日执行的39名外国人遣返案件之中。

除了涉嫌假投资活动，这次移民执法也涉及其他违规情况，包括：

- 持有访问居留许可却从事不符合许可目的的活动。
- 逾期居留。
- 涉及其他违法或不当商业活动。
- 使用不符合规定的居留或旅行文件。

移民局表示，将持续与巴厘岛警方合作，加强对外国人活动的监督。

需要特别说明的是，20人的假投资案件目前应以官方公布的涉嫌及调查结果理解，不应直接将所有相关人员视为已经法院定罪。

**给在巴厘岛旅游及长期居留的外国人提醒：**

如果有人通过社交媒体、私人聚会或通讯软件向你推荐高报酬投资，尤其是声称有特殊渠道、保证获利或要求转账到私人账户，应先查明公司背景及合法性。

不要因为对方也是外国人，或住在巴厘岛的Villa、Co-working Space，就轻易相信投资邀约。

旅游期间也应避免参与自己不熟悉的商业活动，以免涉及违反当地法律或签证规定。
