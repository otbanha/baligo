# **巴厘岛最新新闻｜11月27日：极端天气警报、网约车新规与北巴厘岛生态文化节**

巴厘岛即将迎来11月底一波较明显的雨季天气变化。BMKG最新警告，11月27日至30日全岛可能出现中雨至特大暴雨，部分海域浪高也可能达到2.5米。

交通方面，巴厘岛已正式实施新的网约租车管理法规，涉及车辆年限、司机资格及平台运营规定。另外，北巴厘岛本周末有生态文化节，库塔也将举办国际刺青艺术展。

## **🌧️ BMKG警告11月27日至30日极端天气！全岛留意暴雨、强风及泥石流**

印尼气象、气候及地球物理局（BMKG）第三区气象中心于11月26日发布最新警告，提醒巴厘岛居民及旅客，11月27日至30日可能出现较强的降雨及强风。

BMKG指出，近期大气环流出现变化，包括气流辐合、Madden-Julian Oscillation（MJO）及赤道罗斯贝波（Equatorial Rossby Wave）等因素，都可能增加巴厘岛的降雨强度。

**11月27日全岛天气概况：**

| 项目 | 预报 |
| --- | --- |
| 整体天气 | 中雨 |
| 气温 | 22–33°C |
| 相对湿度 | 65–98% |
| 风向 | 东风至西南风 |
| 风速 | 4–30公里/小时 |
| 北部海域浪高 | 0.25–1米 |
| 南部海域浪高 | 0.25–2米 |

**11月27日至30日特别警戒：**

BMKG提醒，巴厘岛九个县市及城市都可能出现中雨至特大暴雨及强风，包括：

- Badung巴东
- Denpasar登巴萨
- Gianyar吉安雅
- Tabanan
- Bangli
- Buleleng布勒伦
- Jembrana珍布拉娜
- Klungkung克隆孔
- Karangasem卡朗阿森

可能引发的灾害包括：

- 道路及低洼地区淹水
- 突发性洪水（Flash Flood）
- 山区土石流
- 树木倒塌及强风造成的设施损坏

**海上活动也需要特别注意。**

BMKG预警指出，11月27日至30日以下海域浪高可能达到1.25–2.5米：

- 巴厘岛南部海域
- 巴东海峡（Selat Badung）
- 巴厘海峡南部
- 龙目海峡南部

这对前往Nusa Penida、Nusa Lembongan及其他离岛的旅客尤其重要。

**给旅客的提醒：**

这几天安排户外行程，建议特别留意金塔马尼、Bedugul、瀑布及山区道路。

如果有搭船或参加浮潜、潜水活动，请在出发前向船公司确认海况及是否正常营运。

目前并没有全岛景点统一关闭的公告，但遇到强降雨时，不建议为了赶行程而冒险通过积水道路或在恶劣海况下出海。

## **🚗 巴厘岛网约租车新规正式生效！车龄限制10年、排气量至少1,000cc**

如果你在巴厘岛经常使用GrabCar、Gojek的汽车叫车服务，这项新规值得留意。

根据Bali Post于11月25日报导，巴厘岛省政府已正式实施《2026年第8号省级法规》（Perda Provinsi Bali No. 8 Tahun 2026），规范以手机应用程序预订的特殊租赁运输服务（Angkutan Sewa Khusus，ASK）。

这项法规其实已于2026年10月27日公布并生效，近期媒体进一步整理了相关规定。

**车辆规格限制：**

| 项目 | 新规定 |
| --- | --- |
| 汽油／燃油车车龄 | 最多10年 |
| 最低引擎排气量 | 1,000cc |
| 电动车最低动力 | 70kW |
| 车辆登记 | 必须在巴厘岛注册 |

**司机资格也有新要求：**

- 必须符合相关驾驶资格及法规。
- 必须具备至少6个月驾驶经验。
- 能够使用印尼语及英语沟通。
- 巴厘语能力列为优先条件。
- 必须保持良好服务态度及穿着整洁。

**网约车平台也受到规范：**

- 必须具备印尼合法法人资格。
- 必须在巴厘岛设立分公司。
- 必须与取得合法运营许可及配额的ASK业者合作。
- 必须提供运营资料及数字管理平台，供省政府监督。

另外，法规也规定政府将设定车辆运营配额，以及运价上下限，并定期检讨。

**对游客有什么影响？**

这项法规的重点，是让巴厘岛网约汽车服务更加制度化，包括车辆安全、司机资格及乘客权益。

不过，目前不能直接推论所有叫车平台都会立即调整服务，也不能将这项ASK汽车租赁规范直接等同于GoRide等摩托车叫车服务的规则。

对旅客而言，最值得注意的是未来网约车的车辆规格、合法运营资格及运价管理可能逐步改变。

目前尚未看到政府公布所有平台的实际转换时程，也没有证据显示旅客现阶段需要额外办理任何手续。

## **🪸 北巴厘岛Pemuteran Bay Festival 11月27日至29日登场！免费入场、结合海洋保育与文化活动**

如果这周末刚好在巴厘岛北部，值得留意Pemuteran Bay Festival 2026。

这是一场以生态旅游、地方文化及海洋保育为主题的年度活动，地点位于Buleleng县Pemuteran村。

印尼观光部官方旅游入口网站目前列出的活动日期为11月27日至29日，并标示免费入场。

**活动信息：**

| 项目 | 信息 |
| --- | --- |
| 活动名称 | Pemuteran Bay Festival 2026 |
| 日期 | 11月27日至29日 |
| 地点 | Pemuteran, Buleleng |
| 主题 | Foresting the Ocean |
| 入场费 | 免费 |

活动内容包括：

- 巴厘岛传统音乐及文化表演
- 当地美食市集
- 瑜伽及户外活动
- 海洋保育讲座
- 珊瑚礁复育工作坊
- Biorock珊瑚复育相关活动
- 海岸及环境保育活动

Pemuteran最值得认识的特色之一，就是当地长期推动的Biorock珊瑚复育计划。

这项技术通过水下金属结构及低电压电流，促进矿物质沉积，协助珊瑚礁复育。Pemuteran也因此成为印尼具有代表性的社区型海洋保育旅游地区。

对喜欢浮潜、潜水及自然生态的旅客而言，这场活动不只是一般音乐或文化节，也能认识当地居民如何结合观光与海洋保育。

**有一点需要特别提醒：活动日期曾出现不同版本。**

10月26日DetikBali报道曾引用巴厘岛省观光局当时的日历，列出11月26日至28日；目前印尼观光部官方活动页面则列为11月27日至29日。

因此，若专程从巴厘岛南部开车前往，建议先向主办单位确认最新活动安排，不要只依据较早的活动日历。

另外，虽然活动免费入场，潜水、浮潜、船只及部分特定体验仍可能需要另外付费。
