# 巴厘岛最新新闻｜11月21日：雨季天气、库塔海滩垃圾、卡塔尔航空增班提案

巴厘岛11月20日的旅游消息，主要集中在雨季带来的海岸环境变化、国际航空连接及周末活动。库塔海岸近期出现大量海漂垃圾，巴东县已累计清除约200吨；另一方面，卡塔尔驻印尼大使提出增加卡塔尔航空直飞巴厘岛班次的构想，未来有望进一步改善中东旅客的交通便利性。

## 🌦️ BMKG预测11月21日多云！中南部及东部留意雷雨，南部海域浪高可能达2米

印尼气象、气候及地球物理局（BMKG）巴厘岛第三区气象中心公布11月21日最新预报，巴厘岛整体以多云为主，但中部、南部及东部地区仍须留意中至大雨及雷电。

**全岛天气概况：**

| 项目 | 11月21日预报 |
| --- | --- |
| 天气 | 多云，局部降雨 |
| 气温 | 20–34°C |
| 相对湿度 | 60–95% |
| 风向 | 东至南风 |
| 风速 | 4–37公里/小时 |
| 北部海域浪高 | 0.25–1米 |
| 南部海域浪高 | 1–2米 |

BMKG特别提醒，中部、南部及东部可能出现中至大雨，并伴随雷电。南部海域也有浪高达2米或以上的可能。

各地预报方面，吉安雅可能出现中等降雨，巴东、塔巴南、登巴萨及其他地区则仍须留意局部降雨。

**对旅客的影响：**

- 乌布、金塔马尼及Bedugul等地，建议准备雨具。
- 瀑布、梯田及山区景点，出发前应确认天气与现场状况。
- 前往努沙佩尼达、努沙蓝梦岛的旅客，应确认船公司最新海况及船班。
- 海边活动及水上运动应依照现场安全指示，不要因为岸边看起来平静就忽略海况。

目前并没有全岛景点统一关闭的公告，旅客不必因为进入雨季就取消所有户外活动，但建议行程保留弹性。

## 🏖️ 库塔海滩出现大量海漂垃圾！巴东自11月5日已清除200吨

巴厘岛西南部海岸开始受到西风季节影响，库塔及巴东其他海岸近期出现大量随海流漂上岸的垃圾，当地清洁单位已加强清理工作。

根据detikBali于11月20日报导，巴东县环境与清洁局（DLHK）自2026年11月5日起，已在各海岸地区累计清除约200吨海漂垃圾。

当局指出，这波垃圾增加与西风季节（Musim Angin Barat）及海流变化有关。

目前清理的垃圾主要包括：

- 大型木头及树枝
- 竹子及树叶
- 海上漂流而来的有机物
- 塑料瓶及一次性包装

为了加快清理速度，Badung县将海岸分成5个清洁作业区，并投入20辆垃圾车及2台大型装载机，将海漂垃圾集中运走。

木材类垃圾会送往Mengwitani垃圾处理设施进行粉碎处理，其他残余垃圾则送往Suwung区域垃圾掩埋场。

**对旅客的影响：**

这是每年雨季前后巴厘岛西岸常见的季节性现象，尤其库塔、雷吉安及周边海岸可能受到海漂垃圾影响。

如果这几天打算安排库塔海滩散步、日落拍照或海边活动，建议不要预设所有海滩都会维持干净的状态。

这并不代表库塔海滩全面关闭，而是部分海岸可能出现垃圾堆积及清洁车辆作业，实际情况会随海流及清理进度改变。

## ✈️ 卡塔尔大使提议每日增加2至3班直飞巴厘岛航班！Qatar Airways有望扩大运能

巴厘岛与中东地区的航空连接可能进一步加强。

卡塔尔驻印尼大使H.E. Dr. Sultan bin Mubarak Saad Al-Dosari于11月19日拜会巴厘岛省长Wayan Koster，提出增加Qatar Airways直飞巴厘岛的航班频率，希望进一步吸引卡塔尔及中东地区旅客。

大使表示，巴厘岛在卡塔尔及中东旅游市场具有相当吸引力，但随着旅客需求增加，也需要提升航空运能。

他提出的构想是：

**每日增加2至3班直飞航班。**

大使也表示，已就相关事项与印尼交通部进行协调，并希望继续与巴厘岛政府沟通。

巴厘岛省长Wayan Koster对这项提议表示支持，认为增加国际航班有助于提升旅游连接及经济合作。

对台湾、香港及新加坡旅客而言，这项消息也值得留意。中东航线不只是服务当地旅客，也是部分欧洲旅客前往巴厘岛的重要转机通道。

不过，目前这仍是增加航班的提议，并不是已经确认的增班计划，尚未公布新增班次的正式时程、票价或实际运营日期。

活动由Ubud Hotel Association及PHRI Gianyar等单位共同举办，主要场地设于：

Central Parking, Monkey Forest Ubud

**两天活动安排：**

| 日期 | 活动 |
| --- | --- |
| 11月21日（六） | 21K Cross Country、Squad Race、Kids Dash |
| 11月22日（日） | 5K、10K |

其中21K越野赛结合乌布周边田野及自然景观，与一般市区路跑有所不同。

主办单位官方网站目前显示，所有组别均已售罄，并明确表示比赛当天不接受现场报名。

活动不只是竞赛，也希望结合健康生活、在地文化及社区参与，让参加者从不同角度认识乌布。

**给周末前往乌布的旅客：**
