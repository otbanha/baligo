# 巴厘岛最新新闻｜11月22日：雨季天气、金塔马尼道路坍塌与旅游管理新政策

巴厘岛11月21日的最新消息，主要集中在雨季交通安全、旅游承载量管理及海上观光安全。BMKG预测11月22日部分地区仍有中至大雨及雷电风险，金塔马尼一条替代道路也因先前豪雨坍塌，至今尚未修复。此外，巴厘岛政府开始研究未来国际游客的合理承载量，住宿业者的合法执照问题也持续受到关注。

## **🌦️ BMKG预测11月22日局部降雨！南部海域浪高可能达2米**

印尼气象、气候及地球物理局（BMKG）巴厘岛第三区气象中心公布11月22日天气预报，整体预测以小雨为主，但东部、中部及西部部分地区仍须留意中至大雨及雷电。

**11月22日天气概况：**

| 项目 | 预测 |
| --- | --- |
| 整体天气 | 小雨 |
| 气温 | 20–34°C |
| 相对湿度 | 60–95% |
| 风向 | 东至南风 |
| 风速 | 4–37公里/小时 |
| 北部海域浪高 | 0.5–1.25米 |
| 南部海域浪高 | 0.75–2米 |

BMKG特别发布降雨提醒，巴厘岛东部、中部及西部部分地区可能出现中至大雨，并伴随雷电。

海象方面，以下区域须留意2米或以上的浪高：

- 巴厘岛海峡南部
- 龙目海峡南部
- 巴东海峡（Selat Badung）
- 巴厘岛南部海域

**对旅客的影响：**

如果安排乌布、金塔马尼、Bedugul等山区景点，建议留意午后降雨及道路状况，避免在暴雨期间行经陡坡或容易发生落石的路段。

前往努沙佩尼达、努沙蓝梦岛及其他离岛的旅客，应向船公司确认最新海况。尤其不要只看出发港口的天气，目的地及航行路线的海况同样重要。

这是局部天气警报，并不代表全岛景点都会关闭，实际情况仍需依照当地最新预报判断。

## **🚧 前往金塔马尼的一条替代道路坍塌！Jalan Pulasari Kawan至今尚未修复**

巴厘岛Bangli县一条通往金塔马尼（Kintamani）的替代道路，因11月初暴雨造成路面坍塌，目前仍处于完全中断状态。

根据11月20日detikBali报道，受影响路段为：

**Jalan Pulasari Kawan**

位置：Pulasari村、Tembuku区、Bangli县。

这条道路在11月初受到豪雨影响，路面出现严重坍塌，导致整段道路无法通行。

11月20日，Bangli县议会相关委员会实地视察后，要求地方政府优先安排修复工程，并进行技术评估，确认道路坍塌的原因及后续施工方案。

不过，这条路属于往返金塔马尼的其中一条替代道路，并不是所有前往金塔马尼的道路都已中断，其他替代路线仍可使用。

**给旅客的提醒：**

- 前往金塔马尼观赏巴杜尔火山及湖景，建议使用主要道路。
- 不要为了节省时间，随意跟随导航进入不熟悉的乡间小路。
- 包车旅客可事先请司机确认当天道路状况。
- 如果遇到暴雨，应避免行经山坡、塌方及积水路段。

目前尚未公布这条道路的确切修复完成日期。

## **🌍 巴厘岛研究国际游客承载量！未来可能制定入岛管理规范**

巴厘岛省长Wayan Koster于11月19日表示，省政府将研究巴厘岛能够长期承受的国际游客数量，并考虑制定相关地方规范，让观光发展与环境、基础设施及文化保存取得平衡。

这项研究主要评估：

- 巴厘岛自然环境的承载能力
- 道路、交通及公共设施容量
- 水资源及垃圾处理能力
- 巴厘岛传统文化与居民生活受到的影响

Koster表示，未来将依据研究结果，准备相关地方自治法规（Perda），作为观光客管理的政策依据。

**但要特别注意，目前并没有正式公布外国游客每日入境配额，也没有宣布新的入境限制或实施日期。** 现阶段仍是研究及政策准备阶段，不能解读为外国旅客即将无法自由前往巴厘岛。

另一方面，巴厘岛政府也持续要求线上订房平台（OTA）停止销售没有合法营业执照的住宿。

省长表示，2025至2026年间约有5,000家Villa业者提出执照申请。政府希望通过住宿业者合法化，改善市场竞争及住宿管理。

对旅客来说，这项政策有一个比较实际的影响：未来通过Agoda、Booking.com、Airbnb等平台搜索住宿时，没有符合当地营业许可要求的住宿，可能无法继续在平台上销售。

这并不代表巴厘岛禁止Villa住宿，也不是所有私人Villa都违法。旅客预订时，建议选择资料清楚、合法经营的住宿，尤其是长期住宿或整栋Villa预订，更应确认业者的营业信息。

巴厘岛未来的观光政策方向，显然正逐渐从单纯追求游客数量，转向环境承载力、住宿合法化及旅游品质管理。

## **🚢 Benoa邮轮码头加强安全检查！提前准备圣诞及新年旅游旺季**

巴厘岛登巴萨的Benoa港口，近期开始加强旅客及邮轮相关安全管理，为2026年圣诞节及2027年新年旅游旺季做准备。

根据11月20日Bali Post报道，Denpasar警方及Benoa港口警察单位已增加码头巡逻，并与港务、海关、Pelindo及检疫单位加强合作。

主要管理项目包括：

- 邮轮及客船进出港监控
- 旅客及行李检查
- 货物及物流管理
- 防止毒品、危险物品及违禁品进入
- 加强码头周边治安巡逻

Benoa是巴厘岛重要的海上旅游入口，除了国内客船，也接待国际邮轮旅客。

Pelindo也持续改善邮轮服务设施，东侧邮轮码头已从350米延长至500米，具备同时停靠两艘大型邮轮的能力。

目前已有76艘邮轮登记计划于2026年停靠Benoa，显示巴厘岛邮轮旅游市场仍在发展。

对一般自由行旅客来说，这项措施不会直接改变机场入境程序；但如果搭乘邮轮抵达巴厘岛，近期可能会遇到较密集的港口安全检查。

目前没有公布新的旅客入港限制或额外收费规定。

## **🏖️ 库塔南部海滩持续加强警察巡逻！提醒游客勿忽略海况及安全标志**

巴厘岛南部的南库塔地区，包括部分悬崖海滩及热门海岸景点，近期持续加强海上及陆地巡逻。

根据Bali Post及NusaBali相关报道，Denpasar警方海上警察单位（Satpolairud）于11月18日继续在库塔南部海域及海滩执行巡逻工作。

巡逻方式包括：

- 使用警用船只巡查海域
- 在容易发生事故的海岸区域进行陆地巡逻
- 观察游客、渔民及海上活动状况
- 遇到危险情况进行劝导及必要的安全处置

警方特别关注海上事故、游客危险活动及海滩公共秩序问题。

库塔南部部分海滩地形特殊，尤其是位于悬崖下方的海滩，紧急救援及撤离可能比一般沙滩困难。

警方提醒游客：

- 遵守海滩上的安全标志及禁止游泳指示。
- 不要在海浪或海流明显增强时勉强下水。
- 不要擅自进入限制区域。
- 前往悬崖海滩时，注意上下坡及回程时间。

这次巡逻并不是宣布库塔南区海滩全面禁止游泳，也没有公布新的统一关闭措施，而是持续性的安全监控。

特别是在雨季及海况不稳定期间，旅客不要只看海滩是否漂亮，也要注意现场海浪、离岸流及救援条件。
