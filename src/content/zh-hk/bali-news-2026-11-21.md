# 峇里島最新新聞｜11月21日：雨季天氣、Kuta海灘垃圾、卡達航空增班提案

峇里島11月20日嘅旅遊消息，主要集中喺雨季帶嚟嘅海岸環境變化、國際航空連結同週末活動。Kuta海岸近期出現大量海漂垃圾，Badung縣已累計清除約200噸；另一方面，卡達駐印尼大使提出增加Qatar Airways直飛峇里島班次嘅構想，未來有望進一步改善中東旅客嘅交通便利性。

## 🌦️ BMKG預測11月21日多雲！中南部及東部留意雷雨，南部海域浪高可能達2米

印尼氣象、氣候及地球物理局（BMKG）峇里島第三區氣象中心公布11月21日最新預報，峇里島整體以多雲為主，但中部、南部及東部地區仍須留意中至大雨及雷電。

**全島天氣概況：**

| 項目 | 11月21日預報 |
| --- | --- |
| 天氣 | 多雲，局部降雨 |
| 氣溫 | 20–34°C |
| 相對濕度 | 60–95% |
| 風向 | 東至南風 |
| 風速 | 4–37公里／小時 |
| 北部海域浪高 | 0.25–1米 |
| 南部海域浪高 | 1–2米 |

BMKG特別提醒，中部、南部及東部可能出現中至大雨，並伴隨雷電。南部海域亦有浪高達2米或以上嘅可能。

各地預報方面，Gianyar可能出現中等降雨，Badung、Tabanan、Denpasar及其他地區則仍須留意局部降雨。

**對旅客嘅影響：**

- 烏布、金塔馬尼同Bedugul等地，建議帶定雨具。
- 瀑布、梯田同山區景點，出發前應確認天氣同現場情況。
- 去努沙佩尼達、努沙藍夢島嘅旅客，應確認船公司最新海況同船班。
- 海邊活動同水上運動應跟足現場安全指示，唔好因為岸邊睇落平靜就忽略海況。

目前並冇全島景點統一關閉嘅公告，旅客唔使因為進入雨季就取消晒所有戶外活動，但建議行程保留彈性。

## 🏖️ Kuta海灘出現大量海漂垃圾！Badung自11月5日已清除200噸

峇里島西南部海岸開始受西風季節影響，Kuta同Badung其他海岸近期出現大量隨海流漂上岸嘅垃圾，當地清潔單位已加強清理工作。

根據detikBali喺11月20日報導，Badung縣環境與清潔局（DLHK）自2026年11月5日起，已喺各海岸地區累計清除約200噸海漂垃圾。

當局話，呢排垃圾增加同西風季節（Musim Angin Barat）同海流變化有關。

而家清理嘅垃圾主要包括：

- 大件木頭同樹枝
- 竹同樹葉
- 海上漂流過嚟嘅有機物
- 膠樽同一次性包裝

為咗加快清理速度，Badung縣將海岸分成5個清潔作業區，仲投入20架垃圾車同2台大型裝載機，將海漂垃圾集中運走。

木頭類垃圾會送去Mengwitani垃圾處理設施進行粉碎處理，其他殘餘垃圾就送去Suwung區域垃圾掩埋場。

**對旅客嘅影響：**

呢個係每年雨季前後峇里島西岸常見嘅季節性現象，尤其係Kuta、Legian同周邊海岸可能會受到海漂垃圾影響。

如果呢幾日打算去Kuta海灘散步、影日落或者玩海邊活動，建議唔好預期所有海灘都會保持乾淨。

呢個唔代表Kuta海灘全面關閉，只係部分海岸可能會有垃圾堆積同清潔車輛喺度作業，實際情況會跟海流同清理進度而改變。

## ✈️ 卡達大使提議每日增加2至3班直飛峇里島航班！Qatar Airways有望擴大運能

峇里島同中東地區嘅航空連接可能會進一步加強。

卡達駐印尼大使H.E. Dr. Sultan bin Mubarak Saad Al-Dosari喺11月19日拜會峇里島省長Wayan Koster，提出增加Qatar Airways直飛峇里島嘅航班次數，希望進一步吸引卡達同中東地區嘅旅客。

大使表示，峇里島喺卡達同中東旅遊市場相當有吸引力，但隨住旅客需求增加，都需要提升航空運力。

佢提出嘅構想係：

**每日增加2至3班直飛航班。**

大使話，已經就相關事項同印尼交通部協調，仲希望繼續同峇里島政府溝通。

峇里島省長Wayan Koster對呢個提議表示支持，認為增加國際航班有助提升旅遊連接同經濟合作。

對台灣、香港同新加坡旅客嚟講，呢個消息都值得留意。中東航線唔單止服務當地旅客，亦係部分歐洲旅客去峇里島嘅重要轉機通道。

不過，目前呢個只係增加航班嘅提議，唔係已經確認嘅增班計劃，仲未公布新增班次嘅正式時間、票價或者實際營運日期。

## 🏃 Ubud Running Festival 11月21日至22日登場！Monkey Forest周邊留意活動人潮

呢個週末，烏布會舉辦Ubud Running Festival 2026，結合跑步、健康生活、文化同社區活動，吸引印尼各地同國際跑手參加。

活動由Ubud Hotel Association同PHRI Gianyar等單位一齊舉辦，主要場地設喺：

Central Parking, Monkey Forest Ubud

**兩日活動安排：**

| 日期 | 活動 |
| --- | --- |
| 11月21日（六） | 21K Cross Country、Squad Race、Kids Dash |
| 11月22日（日） | 5K、10K |

其中21K越野賽結合烏布周邊嘅田野同自然景觀，同一般市區路跑好唔同。

主辦單位官方網站目前顯示，所有組別都已經賣晒，仲明確表示比賽當日唔接受現場報名。

活動唔止係比賽，仲想結合健康生活、在地文化同社區參與，等參加者從唔同角度認識烏布。

**俾週末去烏布嘅旅客：**

- 11月21日至22日Monkey Forest Central Parking周邊會有活動同參賽人潮。
- 去Monkey Forest、烏布市中心同附近餐廳，建議預留交通時間。
- 如果冇參賽，都可以留意現場活動資訊同觀賽安排。
- 比賽期間請跟住現場交通指示行駛，唔好假設平時嘅接送位置一定用得。

如果本來就打算週末住喺烏布，呢個都係一個可以感受當地運動同社區文化嘅活動。
