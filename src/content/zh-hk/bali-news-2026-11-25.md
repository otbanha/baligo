# **峇里島最新新聞｜11月25日：雨季豪雨警報、離島快艇加強檢查同外國人遣返**

峇里島雨季持續帶來天氣同交通方面嘅挑戰。BMKG最新預報指出，11月25日部分地區仍有中至大雨同雷電可能，Bedugul、金塔馬尼同Besakih等景點都要留意天氣變化。

另外，隨住聖誕節同新年旅遊旺季接近，峇里島警方開始加強海上交通安全檢查，特別係往返努沙佩尼達嘅快艇。移民局都公布最新外國人遣返案件，而Sanur就有一場印度文化節正在舉行。

## **🌧️ BMKG預警11月25日部分地區大雨！金塔馬尼、Bedugul同Besakih留意雷雨**

印尼氣象、氣候同地球物理局（BMKG）峇里島第三區氣象中心喺11月24日發布最新預警，預測11月24日至27日期間，峇里島部分地區可能出現中至大雨，仲會伴隨雷電。

**11月25日全島天氣概況：**

| 項目 | 預報 |
| --- | --- |
| 整體天氣 | 落緊小雨，局部可能比較大 |
| 氣溫 | 20–33°C |
| 相對濕度 | 70–98% |
| 風向 | 東南至西南風 |
| 風速 | 4–30公里／小時 |
| 北部海域浪高 | 0.25–1公尺 |
| 南部海域浪高 | 0.5–2.5公尺 |

BMKG針對唔同時段發布嘅降雨警戒：

- **11月25日至26日上午8點：** Badung、Bangli、Buleleng、Karangasem同Tabanan可能會落中等雨。
- **11月26日至27日上午8點：** Badung、Buleleng同Tabanan進入大雨警戒，Bangli、Denpasar、Karangasem、Gianyar同Klungkung就要留意中等雨。

另外，BMKG特別點名11月25日以下旅遊地區可能會落雨同雷電：

- Bedugul（貝都古）
- Kintamani（金塔馬尼）
- Besakih（母廟）

**對旅客嘅影響：**

如果聽日安排金塔馬尼火山景觀、Bedugul湖區或者Besakih母廟，建議保留行程彈性，避免喺雷雨期間進行山區戶外活動。

南部海域浪高可能達到2.5米，去努沙佩尼達、努沙藍夢島嘅旅客，應該喺出發前確認快艇公司係咪正常營運。

雨季唔代表成日都會落雨，但呢幾日唔建議將瀑布、山區同海上活動排得太密。

## **🚤 峇里島警方出動4艘巡邏船！努沙佩尼達快艇加強安全檢查**

隨住聖誕節同2027年新年旅遊旺季就嚟到，峇里島警方海上警察單位（Ditpolairud Polda Bali）已經啟動港口整合安全巡邏，派出4艘巡邏船，加強峇里島各海上交通入口嘅管理。

根據11月24日Bali Post報導，警方特別關注Badung海峽（Selat Badung），包括Sanur同Kusamba來往努沙佩尼達嘅快艇航線。

今次安全管理分為兩個層面：

**港口檢查**

警方同港務單位喺各港口進行出航前檢查，主要確認：

- 船上乘客人數同乘客名冊係咪一致。
- 有冇超載情況。
- 救生衣數量係咪符合乘客人數。
- 滅火器同救生艇係咪正常用得。

如果船隻設備唔符合安全要求，就唔准出海。

**海上巡邏**

4艘巡邏船會加強容易發生意外嘅航線監控，特別係來往努沙佩尼達嘅快艇，避免船隻高速行駛、危險爬頭或者切入大型船隻航道。

警方亦會同BMKG、Basarnas印尼搜救單位同海軍合作，根據天氣同海況調整巡邏同安全管理。

**對旅客嘅影響：**

呢項措施對搭Sanur去Nusa Penida、Kusamba去Nusa Penida快艇嘅旅客尤其重要。

建議：

- 揀有正式營運同安全設備嘅快艇公司。
- 唔好為咗趕時間揀超載嘅船。
- 出發前確認救生衣同安全設備。
- 雨季期間唔好淨係信船公司嘅原定時間表，要確認當日係咪正常開船。

今次加強檢查並唔代表離島航線全面停航，而係希望喺年底旺季嚟之前，降低海上交通意外嘅風險。

## **🛂 峇里島移民局再遣返5個外國人！包括逾期居留同持訪問簽證經營紋身店**

峇里島Denpasar移民拘留中心（Rudenim Denpasar）喺11月24日公布，最近總共遣返5個違反印尼移民規定嘅外國人，國籍包括俄羅斯、葉門、印度同澳洲。

呢批案件入面，公開嘅違規情況包括：

| 國籍 | 違規情況 |
| --- | --- |
| 俄羅斯 | 逾期居留45日 |
| 印度 | 逾期居留187日 |
| 葉門 | 逾期居留64日 |
| 澳洲 | 持訪問簽證喺庫塔經營紋身生意 |
| 澳洲 | 逾期居留787日，超過兩年 |

移民局認為，持有訪問簽證唔代表可以喺峇里島從事未獲許可嘅商業活動，所以依法執行遣返。

另一個澳洲籍人士逾期居留787日，時間已經超過兩年。

移民拘留中心負責人Teguh Mentalyadi表示，外國人喺印尼必須遵守相同嘅移民規定，遣返程序要喺完成行政手續同旅行文件準備之後執行。

移民拘留中心負責人Teguh Mentalyadi表示，外國人喺印尼必須遵守相同嘅移民規定，遣返程序要喺完成行政手續同旅行文件準備之後先執行。

**俾旅客同長期居留嘅朋友提提你：**

- VOA同eVOA一定要喺批准嘅停留期限內離境，或者依法申請延期。
- 訪問簽證唔等於工作許可。
- 就算喺峇里島搞啲細規模嘅商業活動，都要確認用嘅簽證同工作許可係咪啱。
- 如果計劃長期居留，唔好等到簽證就快到期先搞延期。

一般觀光客唔需要因為呢類案件太過擔心，但係簽證期限同實際活動係咪符合許可範圍，真係唔可以唔理嘅事。
