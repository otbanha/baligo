# 印尼QRIS係咩嚟？2026峇里島旅遊「無現金支付」完全解析

去峇里島旅行，你一定會喺路邊攤、超市、按摩店，甚至海灘俱樂部嘅櫃枱上，見到一張印住彩色方塊圖案嘅細卡片，旁邊寫住「QRIS」。呢個其實係印尼全國統一嘅流動支付QR Code標準，亦係呢幾年當地人消費習慣快速改變嘅關鍵。呢篇文章就嚟完整講解QRIS係咩嚟、台灣旅客可唔可以直接掃碼俾錢，同埋喺峇里島實際可行嘅無現金支付方式。

![raw-image](https://images.gobaligo.id/images/2026-08/1786361369033-kjc6my8wmxwkk4flysvvmmknrmekbidltfkklf1y.png)

## QRIS到底係咩？

QRIS全名係「Quick Response Code Indonesian Standard」，由印尼央行（Bank Indonesia）喺2019年推出，目的係統一境內原本各自為政嘅流動支付QR碼。喺QRIS出現之前，GoPay、OVO、DANA呢啲電子錢包各有各嘅付款碼，舖頭成日要貼出一整排QR碼俾唔同用戶掃描，非常混亂。QRIS上線之後，商戶只需要一組QR碼，無論消費者用邊個App，都可以掃同一組碼完成付款——概念上同台灣而家推廣嘅TWQR相當類似。

呢個系統普及嘅速度相當驚人。根據印尼央行公布嘅資料，截至2026年第一季，QRIS交易量年增率已經超過133%，單係峇里島當地使用QRIS嘅商戶就超過110萬間，用戶數突破115萬人。由路邊嘅Nasi Goreng攤販到連鎖超市Indomaret、Alfamart，幾乎都已經支援QRIS掃碼付款。

## 台灣旅客可唔可以直接用手機掃QRIS俾錢？

呢個係好多人最想知嘅問題，答案係：**暫時仲未得**。

印尼央行近年積極推動「QRIS跨境（QRIS Antarnegara / QRIS Cross-border）」計劃，令部分國家嘅旅客可以直接用自己國家嘅流動支付App，掃描印尼當地嘅QRIS碼俾錢，反之亦然。截至2026年中，已經正式開通嘅合作國家包括泰國、馬來西亞、新加坡、日本、南韓同中國，印尼央行亦正同沙烏地阿拉伯、印度進行跨境QRIS嘅試點。

不過，台灣暫時唔喺呢份合作名單入面，所以好似LINE Pay、街口支付呢啲台灣成日用嘅行動支付App，暫時冇得直接掃峇里島舖頭嘅QRIS碼埋單。想喺峇里島用手機無現金消費，都係要靠當地嘅電子錢包先搞得掂。

## 峇里島實際可行：申請當地電子錢包

![raw-image](https://images.gobaligo.id/images/2026-08/1786361435327-2024_11_11_157146_1731331014._large.jpg)

▲QRIS除咗可以喺所有超市、便利店用，愈來愈多舖頭，甚至路邊小販都用得

好消息係，申請印尼本地電子錢包一啲都唔難，用台灣手機號碼就可以註冊，而且幾乎都掃到QRIS消費。目前最主流嘅三個選擇係GoPay、DANA、OVO：

- **GoPay**：附屬喺超級App Gojek，除咗俾錢，仲可以叫車、叫外賣，係外國旅客最常用嘅入門選擇，註冊門檻亦最低。不過要留意，GoPay目前唔開放外國信用卡直接綁定增值，主要增值方式係去Indomaret、Alfamart呢啲超市用現金增值，或者請Gojek司機幫手代增值。部分教學都話可以用海外金融卡（Debit Card）免手續費增值，但實際成唔成功就視乎發卡銀行，建議去到之後現場試吓小額增值。
- **DANA**：對外國旅客比較友善嘅一點係，可以直接綁定Visa或萬事達卡嘅外國卡進行QRIS付款，唔需要印尼當地身份證（KTP），流程相對簡單。
- **OVO**：同樣支援QRIS付款，但部分進階功能有時需要當地身份驗證，適合做後備選項。

實際上，建議主力用GoPay（因為叫車、外賣、付款一次搞掂），再另外準備DANA作為碌卡付款嘅後備，現金都留返啲細額，因為部分細舖有時仲係只收現金。

## 用QRIS消費嘅基本流程

1. 打開電子錢包App（以GoPay為例）
2. 㩒「掃描」或者「Scan QR」功能
3. 對準舖頭枱面或者收銀處嘅QRIS碼
4. 確認商戶名同銀碼冇錯之後，輸入密碼或者指紋完成付款
5. 螢幕出現付款成功畫面就搞掂，唔使簽名或者額外手續

![raw-image](https://images.gobaligo.id/images/2026-08/1786361812303-banner_news_qris_edc_fe1cee70f3.jpg)

QRIS付款冇最低金額限制，就算係美金$0.03咁細額嘅消費都用得，呢個都係點解連路邊攤販都肯申請QRIS嘅原因。

## 用QRIS時要注意嘅嘢

- **付款前一定要核對商戶名**：QRIS碼通常會顯示收款商戶名，付款前先確認個名同眼前間舖頭相符，避免掃到錯嘅或者假嘅QR碼。
- **銀碼一定要自己輸入或者核對**：多數QRIS係「動態碼」，掃描之後App會自動彈出銀碼，但都建議付款前再確認吓銀碼啱唔啱。
- **保留付款成功畫面**：有時網絡唔穩定會搞到扣款狀態唔清唔楚，建議保留交易紀錄截圖，方便日後對數。
- **App儲值餘額要控制**：因為儲值之後啲餘額多數綁定喺App入面，建議按當次旅程需要少量多次咁儲值，避免戶口入面留太多餘額。

## 常見問題

**Q：一定要用印尼電子錢包先消費得㗎，信用卡唔用得咩？** 峇里島市區嘅酒店、餐廳、購物中心多數都仲可以直接碌卡（Visa／Mastercard），QRIS主要係解決小型商戶、路邊攤、傳統市場呢啲以前只可以收現金嘅消費場景，兩種方法可以互相配合使用。一般可以碌卡嘅舖頭一定可以用QRIS；可以用QRIS嘅舖頭就唔一定可以碌卡。

**Q：儲值會收手續費㗎？** 便利店現金儲值通常會有小額手續費，實際費率視乎App同儲值渠道而異，儲值之前可以喺App入面確認當時嘅費用說明。

**問：QRIS未來會唔會開放台灣直接跨境支付？** 印尼央行嘅QRIS跨境合作名單仲喺度不斷增加，最近陸續加入日本、南韓、中國，仲試點沙烏地阿拉伯同印度，至於會唔會納入台灣就要留意官方之後嘅公佈。
