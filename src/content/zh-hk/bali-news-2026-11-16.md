## 峇里島11月16日天氣展望：多處預測有雨，Tabanan同Bangli要留意雨勢

印尼氣象、氣候及地球物理局（BMKG）最新預報顯示，2026年11月16日峇里島多個縣市可能出現降雨，整體仲係處於雨季天氣型態。

根據BMKG目前嘅縣市預報：

| 地區 | 11月16日預測 |
| --- | --- |
| 登巴薩（Denpasar） | 多雲 |
| 巴東縣（Badung） | 小雨 |
| 吉安雅縣（Gianyar） | 小雨 |
| 克隆孔縣（Klungkung） | 多雲 |
| Tabanan | 小雨至中等降雨 |
| Bangli | 小雨 |
| 卡朗阿森（Karangasem） | 小雨 |
| 布勒倫（Buleleng） | 小雨 |
| 珍布拉娜（Jembrana） | 小雨 |

全島各地預測氣溫大約19–32°C，相對濕度最高可能接近99%。

海象方面，BMKG預測峇里島北部海域浪高約0.5–1.25公尺，南部海域約1–2公尺。海況仍然要根據出發當日嘅港口同船公司公告確認。

對旅客嚟講，聽日如果安排烏布、Bedugul、Jatiluwih梯田或者瀑布景點，建議預留天氣彈性。雨季唔代表全日落雨，但午後戶外活動可能受局部雨勢影響。

如果要去努沙佩尼達、努沙藍夢島等離島，都建議出發前確認海況同船班。

資料：BMKG峇里島縣市預報及BBMKG Region III。

## **Sanur電動接駁巴士導入QRIS Tap！11月15日至30日優惠價68印尼盾**

峇里島嘅數碼支付應用開始延伸到地方觀光交通。

印尼銀行峇里島分行喺11月14日喺沙努爾舉行嘅Baligivation 2026活動中，正式將QRIS同QRIS Tap支付功能導入由Desa Adat Intaran營運嘅電動接駁巴士。

呢項服務主要喺Sanur當地觀光區域運行，等居民同遊客可以用數碼方式畀交通費。

目前接駁巴士資料如下：

- 營運單位：Desa Adat Intaran
- 車輛數量：12架
- 每架容量：最多10個乘客
- 一般票價：每人5,000印尼盾
- 支付方式：QRIS同QRIS Tap

為咗推廣數碼交易，印尼銀行同峇里島政府推出限時優惠：

優惠期間 11/15–11/30

每人每趟優惠價：Rp68

優惠價格配合峇里島省政府成立68週年嘅象徵數字，仲設有每日名額限制。

對旅客嚟講，呢項措施係沙努爾地方接駁交通數碼化嘅新嘗試。不過，實際乘車路線、每日優惠名額同付款支援方式仲要以現場資訊為準。

## 峇里島同日本深化合作！觀光、投資同青年赴日就業成為重點

峇里島省長Wayan Koster希望進一步加強峇里島同日本嘅合作關係，並將雙方交流從外交同文化層面，推進到更具體嘅經濟同社會合作。

Koster提出嘅合作方向包括：

- 觀光產業合作
- 日本企業喺峇里島嘅投資
- 峇里島青年去日本打工
- 技術同職業技能培訓
- 加強地方政府同日本企業嘅交流

省長特別提到，峇里島嘅技職學校（SMK）畢業生如果具備符合日本市場需求嘅技能，將來可以爭取更多海外就業機會。

Koster亦話，部分而家喺日本打工嘅峇里島青年，對工作環境同收入表現都畀出正面評價。

不過，今次傾偈主要係提出合作方向，仲未公布新嘅正式就業計劃、招聘名額或者具體投資協議。

對峇里島嚟講，日本唔單止係重要嘅國際旅遊市場，仲可能成為未來人才培育同產業合作嘅重要夥伴。

## 峇里島電力備轉率得16.18%！電動車增加，PLN加強充電設施建設

峇里島用電需求持續增加，電力備轉容量近期成為值得關注嘅議題。

5MW，可供電能力係1,678MW，電力備轉率大約16.18%。

呢個數字只係略高過地方電力系統通常要求嘅15%最低備轉標準。

另一方面，峇里島電動車數量都持續增長。

截至2026年9月，峇里島登記嘅電動車已經有18,034架，其中：

- 電動汽車：超過6,700架
- 電動機車：超過11,000架

其中，2026年前9個月嘅電動汽車數量，相比2025年底大約增長咗100%。

PLN峇里島分行表示，未來會繼續確保供電穩定，並加強充電設施建設，以配合電動車生態系統發展。

呢個消息唔代表峇里島就快出現電力短缺，而係顯示當地電力需求同能源轉型需要同步管理。

對旅客嚟講，如果用電動車租賃服務，將來充電設施嘅分佈同供電穩定性，會係影響旅遊便利性嘅重要因素。

## **Bangli舉行I Gusti Ngurah Rai英雄紀念旗幟巡行！聽日會移交Gianyar**

峇里島Bangli縣喺11月15號舉行紀念印尼民族英雄I Gusti Ngurah Rai嘅旗幟同歷史文書巡行活動，配合印尼11月10號Hari Pahlawan（英雄日）嘅紀念安排。

呢次活動由Bangli縣政府主辦，巡行隊伍由Klungkung縣移交嘅Pataka旗幟同Ngurah Rai歷史文書開始，喺Bangli市區Alun-Alun Bangli舉行交接儀式。

之後，巡行隊伍經過Bangli多個地區，包括：

- Peninjoan
- Tembuku
- Suter
- Manikliyu
- Landih
- Pengotan
- Kintamani
- Susut
- Penglipuran英雄墓園（TMP Penglipuran）

Bangli縣長Sang Nyoman Sedana Arta表示，希望透過呢個活動令後生一代認識I Gusti Ngurah Rai嘅歷史同峇里島喺印尼獨立運動中嘅角色。

巡行活動會喺11月16日繼續，並移交畀Gianyar縣政府。

呢個活動屬於地方歷史紀念儀式，唔係專為觀光客設計嘅旅遊表演。如果旅客聽日喺Bangli或Gianyar部分道路遇到巡行隊伍，可能要留意短暫嘅交通影響。
