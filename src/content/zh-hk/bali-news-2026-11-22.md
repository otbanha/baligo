# 峇里島最新新聞｜11月22日：雨季天氣、金塔馬尼路陷同旅遊管理新政策

峇里島11月21日嘅最新消息，主要集中喺雨季交通安全、旅遊承載量管理同海上觀光安全。BMKG預測11月22日部分地區仲有中至大雨同雷電風險，金塔馬尼一條替代道路亦因為之前豪雨路陷，到而家都未整返好。另外，峇里島政府開始研究未來國際遊客嘅合理承載量，住宿業者嘅合法牌照問題亦持續受到關注。

## **🌦️ BMKG預測11月22日局部降雨！南部海域浪高可能去到2米**

印尼氣象、氣候同地球物理局（BMKG）峇里島第三區氣象中心公布11月22日天氣預報，整體預測以小雨為主，但東部、中部同西部部分地區仍然要留意中至大雨同雷電。

**11月22日天氣概況：**

| 項目 | 預測 |
| --- | --- |
| 整體天氣 | 小雨 |
| 氣溫 | 20–34°C |
| 相對濕度 | 60–95% |
| 風向 | 東至南風 |
| 風速 | 4–37公里／小時 |
| 北部海域浪高 | 0.5–1.25米 |
| 南部海域浪高 | 0.75–2米 |

BMKG特別發布降雨提醒，峇里島東部、中部同西部部分地區可能會出現中至大雨，仲會伴隨雷電。

海象方面，以下區域要留意2米或以上嘅浪高：

- 峇里島海峽南部
- 龍目海峽南部
- 巴東海峽（Selat Badung）
- 峇里島南部海域

**對旅客嘅影響：**

如果安排咗烏布、金塔馬尼、Bedugul呢啲山區景點，建議留意午後落雨同道路狀況，避免喺大雨期間行經陡坡或者容易有落石嘅路段。

去努沙佩尼達、努沙藍夢島或者其他離島嘅旅客，應該向船公司確認最新海況。尤其唔好淨係睇出發港口嘅天氣，目的地同航行路線嘅海況一樣咁重要。

呢個係局部天氣警報，唔代表全島景點都會關閉，實際情況仍然要根據當地最新預報判斷。

## **🚧 去金塔馬尼嘅一條替代道路冧咗！Jalan Pulasari Kawan到而家都未整返好**

峇里島Bangli縣一條通往金塔馬尼（Kintamani）嘅替代道路，因為11月初大雨搞到路面冧咗，到而家仲係完全中斷嘅狀態。

根據11月20日detikBali報導，受影響嘅路段係：

**Jalan Pulasari Kawan**

位置：Pulasari村、Tembuku區、Bangli縣。

呢條路喺11月初受到暴雨影響，路面出現嚴重坍塌，搞到成段路冇得行。

11月20日，Bangli縣議會相關委員會實地視察之後，要求地方政府優先安排修復工程，並進行技術評估，確認道路坍塌嘅原因同後續施工方案。

不過，呢條路係來往金塔馬尼嘅其中一條替代道路，唔係所有去金塔馬尼嘅路都斷咗，其他替代路線仍然用得。

**俾旅客嘅提醒：**

- 去金塔馬尼睇巴杜爾火山同湖景，建議用主要道路。
- 唔好為咗慳時間，隨便跟導航走入唔熟嘅鄉村小路。
- 包車旅客可以事先請司機確認當日道路狀況。
- 如果遇到暴雨，應該避免行經山坡、冧山泥同積水嘅路段。

目前仲未公佈呢條路嘅確實修復完成日期。

## **🌍 峇里島研究國際遊客承載量！未來可能制定入島管理規範**

峇里島省長Wayan Koster喺11月19日表示，省政府會研究峇里島可以長期承受嘅國際遊客數量，仲考慮制定相關嘅地方規範，令觀光發展同環境、基礎設施同文化保存取得平衡。

呢項研究主要評估：

- 峇里島自然環境嘅承載能力
- 道路、交通同公共設施容量
- 水資源同垃圾處理能力
- 峇里島傳統文化同居民生活受到嘅影響

Koster表示，未來會根據研究結果，準備相關嘅地方自治法規（Perda），作為觀光客管理嘅政策依據。

**但要特別注意，目前並冇正式公布外國遊客每日入境配額，亦都冇宣布新嘅入境限制或者實施日期。** 現階段仲係研究同政策準備嘅階段，唔可以解讀成外國旅客就快冇得自由去峇里島。

另一方面，峇里島政府亦持續要求線上訂房平台（OTA）停止銷售冇合法營業牌照嘅住宿。

省長表示，2025至2026年間大約有5,000間Villa業者提出牌照申請。政府希望透過住宿業者合法化，改善市場競爭同住宿管理。

對旅客嚟講，呢項政策有一個比較實際嘅影響：將來透過Agoda、Booking.com、Airbnb呢啲平台搜尋住宿嗰陣，冇符合當地營業許可要求嘅住宿，可能冇得繼續喺平台上面銷售。

呢個並唔代表峇里島禁止Villa住宿，亦唔係所有私人Villa都違法。旅客預訂嗰陣，建議揀資料清楚、合法經營嘅住宿，特別係長期住宿或者成棟Villa預訂，更加要確認業者嘅營業資訊。

峇里島未來嘅觀光政策方向，明顯正逐漸由單純追求遊客數量，轉向環境承載力、住宿合法化同旅遊品質管理。

## **🚢 Benoa郵輪碼頭加強安全檢查！提前準備聖誕同新年旅遊旺季**

峇里島登巴薩嘅Benoa港口，近期開始加強旅客同郵輪相關安全管理，為2026年聖誕節同2027年新年旅遊旺季做準備。

根據11月20日Bali Post報導，Denpasar警方同Benoa港口警察單位已經增加碼頭巡邏，並同港務、海關、Pelindo同檢疫單位加強合作。

主要管理項目包括：

- 郵輪同客船進出港監控
- 旅客同行李檢查
- 貨物同物流管理
- 防止毒品、危險物品同違禁品進入
- 加強碼頭周邊治安巡邏

Benoa係峇里島重要嘅海上旅遊入口，除咗國內客船，仲會接待國際郵輪旅客。

Pelindo亦持續改善郵輪服務設施，東邊嘅郵輪碼頭已經由350米延長到500米，可以同時停泊兩艘大型郵輪。

目前已經有76艘郵輪登記計劃喺2026年停靠Benoa，顯示峇里島郵輪旅遊市場仍然喺度發展緊。

對一般自由行旅客嚟講，呢項措施唔會直接改變機場入境程序；但如果你搭郵輪嚟峇里島，近期可能會遇到比較密集嘅港口安全檢查。

目前冇公佈新嘅旅客入港限制或者額外收費規定。

## **🏖️ Kuta Selatan海灘持續加強警察巡邏！提醒遊客唔好忽略海況同安全標誌**

峇里島南部嘅南庫塔地區，包括部分懸崖海灘同熱門海岸景點，最近持續加強海上同陸地巡邏。

根據Bali Post同NusaBali相關報導，Denpasar警方海上警察單位（Satpolairud）喺11月18日繼續喺Kuta Selatan海域同海灘執行巡邏工作。

巡邏方式包括：

- 用警用船隻巡查海域
- 喺容易發生意外嘅海岸區域進行陸上巡邏
- 觀察遊客、漁民同海上活動狀況
- 遇到危險情況時進行勸導同必要嘅安全處置

警方特別關注海上意外、遊客危險活動同海灘公共秩序問題。

Kuta Selatan部分海灘地形特殊，尤其係喺懸崖下面嘅海灘，緊急救援同撤離可能會比一般沙灘困難。

警方提醒遊客：

- 遵守海灘上嘅安全標誌同禁止游泳指示。
- 唔好喺海浪或者海流明顯增強嘅時候勉強落水。
- 唔好擅自走入限制區域。
- 去懸崖海灘嗰陣，留意上落坡同回程時間。

呢次巡邏唔係宣布Kuta Selatan海灘全面禁止游泳，亦冇公佈新嘅統一關閉措施，而係持續性嘅安全監控。

特別係雨季同海況唔穩定嘅時候，旅客唔好淨係睇海灘靚唔靚，都要留意現場海浪、離岸流同救援條件。
