# 峇里島最新新聞｜11月26日：雨季天氣、吉隆坡新航線同年底物價警戒

峇里島11月25日嘅旅遊消息，除咗雨季天氣同海況提醒，航空交通都有新發展。TransNusa宣布12月起開通峇里島直飛吉隆坡航線，令旅客有更多東南亞轉機同多國旅遊選擇。

另一方面，印尼央行開始警告年底假期可能會令物價上升，峇里島移民局都公布咗一單涉及外國人嘅跨國假投資案件。

## 🌦️ 11月26日峇里島天氣：中部同東部部分地區有雨，南部海域浪高約2.1米

印尼氣象、氣候同地球物理局（BMKG）11月25日更新峇里島各縣市天氣預報，11月26日全島仍然以多雲同局部降雨為主。

**11月26日各地天氣預測：**

| 地區 | 天氣 | 氣溫 |
| --- | --- | --- |
| Denpasar登巴薩 | 小雨 | 25–31°C |
| Badung巴東 | 小雨 | 24–31°C |
| Gianyar吉安雅 | 中雨 | 23–30°C |
| Tabanan | 中雨 | 22–27°C |
| Bangli | 中雨 | 19–26°C |
| Klungkung克隆孔 | 小雨 | 26–32°C |
| Karangasem卡朗阿森 | 小雨 | 20–28°C |
| Buleleng布勒倫 | 多雲 | 24–31°C |
| Jembrana珍布拉娜 | 小雨 | 22–29°C |

從預報嚟睇，Tabanan、Gianyar同Bangli要特別留意降雨，其他地區都唔可以完全排除午後降雨。

**海象方面：**

BMKG海洋氣象預報顯示，11月26日峇里島南部印度洋海域浪高大約1.9至2.1米，屬於中等浪況；峇里島海域其他部分區域就大約0.8至1.2米。

對旅客嚟講，最需要注意嘅係離島同海上活動。

如果安排去努沙佩尼達、努沙藍夢島或者南部海岸玩水上活動，建議先同船公司確認當日海況同出航安排。

山區方面，去烏布、金塔馬尼同Bedugul，都建議保留行程彈性，特別係瀑布、山路同戶外活動。

目前冇全島景點統一關閉嘅消息，實際情況應該以當地最新天氣同海況公告為準。

## ✈️ TransNusa開通峇里島直飛吉隆坡！12月10日起每週4班

峇里島同馬來西亞之間將會多一條直飛航線。

印尼航空公司TransNusa宣布，由2026年12月10日起，正式開通峇里島登巴薩（DPS）來回吉隆坡國際機場（KUL）嘅直飛航班。

呢條係TransNusa今年從峇里島出發嘅第三條國際航線，之前已經陸續開通普吉島同墨爾本航線。

**航班資訊：**

| 項目 | 資訊 |
| --- | --- |
| 航空公司 | TransNusa |
| 航線 | Denpasar DPS－Kuala Lumpur KUL |
| 開航日期 | 2026年12月10日 |
| 每週班次 | 4班 |
| 飛行方式 | 直飛 |

**航班時間：**

| 航班 | 出發 | 抵達 |
| --- | --- | --- |
| 8B601 | 峇里島 11:00 | 吉隆坡 14:05 |
| 8B602 | 吉隆坡 14:40 | 峇里島 18:05 |

航班時間都係當地時間。

每星期營運日係星期一、四、五同日。

TransNusa仲話，呢條航線會提供單一機票預訂同行李直掛服務，對由墨爾本、伯斯出發，經峇里島轉去吉隆坡嘅旅客特別方便。

行李方面，航空公司公布嘅方案包括至少20公斤免費託運行李，同7公斤手提行李。

**對台灣同其他華語市場旅客嘅影響：**

呢條航線唔單止增加峇里島同馬來西亞之間嘅交通選擇，仲令安排印尼、馬來西亞同澳洲多國旅遊嘅旅客有更多組合。

如果原本計劃喺峇里島度假之後去吉隆坡，12月10號之後可以多啲比較TransNusa同其他航空公司嘅價錢同時間。

訂飛之前都建議確認實際航班日期、票價、行李規定同埋係咪符合轉機條件。

## 💰 印尼央行警告年底物價上漲壓力！聖誕新年加上2027年Galungan節慶

印尼央行峇里島代表處於11月25日提醒，峇里島年底至明年初可能面對較大嘅通脹壓力。

主要原因係2026年聖誕節同新年假期（Nataru），之後又遇上2027年1月嘅Galungan同Kuningan傳統節慶。

呢幾個時段嘅消費需求疊加，可能會增加食品同日常用品嘅供應壓力。

印尼央行峇里島代表Achris Sarwani指出，峇里島常住人口大約450萬至500萬人，但來自峇里島以外嘅旅客流量可能接近2,000萬人次，龐大嘅消費需求對當地物價管理構成挑戰。

**目前幾項值得留意嘅數字：**

| 項目 | 數據 |
| --- | --- |
| 2026年1至10月累積通脹率 | 2.74% |
| 通脹目標上限 | 3.5% |
| 剩餘目標空間 | 0.76個百分點 |
| 已執行市場平價措施 | 約377次 |

央行亦指出，部分食品嘅現有庫存只能滿足唔夠兩週嘅需求，所以要求地方物價控制小組（TPID）加強市場供應同價格監控。

**最需要留意嘅時間：**

2026年12月10日至2027年1月31日，大約7個禮拜。

呢段時間除咗聖誕節同新年旅遊旺季，仲會遇到峇里島重要嘅Galungan同Kuningan節慶，當地食品同家庭用品需求可能會再增加。

**對旅客嘅影響：**

呢個警告主要針對食品同民生用品供應，唔係官方宣佈旅館、機票或景點門票會全面加價。

不過，如果計劃年底長住、租Villa自己煮飯，或者成日喺當地市場買食材，就要留意超市同市場嘅價格。

另外，12月底至1月嘅旅遊旺季，住宿同交通都建議早啲預訂，唔好等到最後一刻先安排。

## ⚠️ 峇里島移民局公佈外國人假投資案件！20人涉嫌組成跨國詐騙網絡

峇里島Ngurah Rai移民局11月25日公佈，近期針對外國人違規活動展開一系列執法，當中有20名外國人涉嫌參與一個針對峇里島其他外國人嘅跨國假投資網絡。

根據移民局負責人Muhammad Novyandri嘅說明，呢20名外國人係喺11月5日於南庫塔（Kuta Selatan）Ungasan地區一次聯合行動中被查獲。

呢單案被列入移民局11月16日至20日執行嘅39名外國人遣返案件之中。

除咗涉嫌假投資活動，今次移民執法仲涉及其他違規情況，包括：

- 持有訪問居留許可但從事唔符合許可目的嘅活動。
- 逾期居留。
- 涉及其他違法或不當商業活動。
- 使用唔符合規定嘅居留或旅行文件。

移民局表示，會繼續同峇里島警方合作，加強對外國人活動嘅監督。

需要特別講明嘅係，20人嘅假投資案件目前應該以官方公布嘅涉嫌及調查結果去理解，唔應該直接將所有相關人員視為已經法院定罪。

**畀喺峇里島旅遊同長期居留嘅外國人提醒：**

如果有人透過社交媒體、私人聚會或通訊軟體向你推薦高回報投資，尤其係聲稱有特殊渠道、保證獲利或要求轉帳到私人戶口，應該先查清楚公司背景同合法性。

唔好因為對方都係外國人，或者住喺峇里島嘅Villa、Co-working Space，就輕易信佢嘅投資邀請。

旅行期間都應該避免參與自己唔熟悉嘅商業活動，以免搞到違反當地法律或者簽證規定。
