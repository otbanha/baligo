# 峇里島最新新聞｜11月24日：暴雨搞到20處災情、沿海高潮警報同新航線恢復

峇里島雨季正式進入要更加警覺嘅時期。11月22日晚間至23日凌晨嘅強降雨，已經喺全島造成20宗災害事件，Kuta、Legian同登巴薩部分道路出現水浸，另外仲發生土石流同人員死亡事故。

除咗天氣，年底旅遊交通都有新消息。Wings Air將於11月27日恢復Jember同峇里島之間嘅直飛航班，Badung就喺呢個週末舉辦大型創意經濟節。

## 🌦️ 11月24日峇里島天氣：多區仲有豪雨可能，南部海域浪高達2公尺

印尼氣象、氣候及地球物理局（BMKG）峇里島第三區氣象中心公布11月24日最新天氣預報，整體以小雨為主，但係都要留意部分地區可能出現中至大雨同雷電。

**11月24日全島天氣概況：**

| 項目 | 預報 |
| --- | --- |
| 天氣 | 小雨，局部可能較強 |
| 氣溫 | 20–33°C |
| 相對濕度 | 70–95% |
| 風向 | 東南至西南風 |
| 風速 | 4–31公里／小時 |
| 北部海域浪高 | 0.5–1公尺 |
| 南部海域浪高 | 0.5–2公尺 |

BMKG提醒，峇里島大部分地區仲有中至大雨同雷電嘅可能，尤其山區、河川周邊同容易積水嘅低窪地區，要留意突發性降雨。

**另外，仲有一樣好易俾旅客忽略嘅警報：沿海高潮淹水（Rob）。**

BMKG第三區已經發出11月23日至25日沿海高潮淹水預警。11月24日適逢滿月同月球近地點（Perigee），可能會令部分沿海地區嘅最高潮位上升。

六個可能受影響嘅縣市同區域包括：

| 地區 | 可能受影響嘅沿海區域 |
| --- | --- |
| Badung巴東 | Kuta、Kuta Selatan、Kuta Utara、Mengwi |
| Gianyar吉安雅 | Blahbatuh、Gianyar、Sukawati |
| Jembrana珍布拉娜 | Jembrana、Melaya、Mendoyo、Negara、Pekutatan |
| Klungkung克隆孔 | Banjarangkan、Dawan、Klungkung、Nusa Penida |
| Denpasar登巴薩 | Denpasar Selatan、Denpasar Timur |
| Tabanan | Kediri、Kerambitan、Selemadeg、Selemadeg Barat、Selemadeg Timur、Tabanan |

呢個警報唔代表上述地區一定會發生淹水，亦唔代表海灘全面關閉，而係提醒沿海低窪地區、港口同海灘活動要留意潮汐變化。

**俾旅客嘅提醒：**

- 住喺Kuta、Seminyak、Sanur同Nusa Dua呢啲沿海區域，可以留意住宿周邊有冇積水。
- 去海灘影相或者散步嗰陣，注意潮位同海浪變化。
- 去Nusa Penida嘅旅客，除咗確認船班，仲要留意碼頭同沿岸狀況。
- 雨勢比較大嘅時候，避免安排瀑布、山區同河谷活動。

## 🚨 峇里島一晚暴雨搞到20個地方出事！Kuta、Legian同登巴薩馬路水浸

11月22號下晝到23號凌晨，峇里島好多地方落咗好大雨，根據峇里島省災害管理局（BPBD）截至11月23號上晝9點嘅統計，成個島總共有20宗災害事件。

https://www.instagram.com/reel/DgD70siy50u/?utm_source=ig_web_copy_link&bqrl=NTc4MTIwNjQ2YQ==

雨量真係好誇張：

| 地區 | 24個鐘累積雨量 |
| --- | --- |
| Tampaksiring | 161毫米 |
| Karangasem | 149毫米 |
| Selemadeg Barat | 111毫米 |

其中Tampaksiring已經達到極端降雨級別。

20個災害事件分佈如下：

- Denpasar：7個地方
- Badung：4個地方
- Tabanan：4個地方
- Jembrana：2處
- Karangasem：2處
- Bangli：1處

主要災情包括道路水浸、樹冧、山泥傾瀉同建築物受損。

**對遊客影響比較直接嘅係Kuta同Legian。**

11月23號上晝，Kuta同Legian部分道路出現積水，有啲路段水深去到成人小腿咁高。Tukad Mati河道亦因為水量增加，出現大量塑膠垃圾同木材塞住橋底嘅情況。

當地清潔人員同相關單位已經開始清理，部分積水慢慢退咗，但仲有啲地方需要泵水同清除障礙物。

另外，當晚同凌晨嘅暴雨亦造成兩單嚴重意外：

- Badung縣Mengwi有個女仔跌落排水渠，俾急流沖走，11月23號下晝搵返，已經不幸過身。
- Karangasem縣Sidemen有個65歲女人俾山泥傾瀉冚住，救援人員喺11月23號上晝搵返遺體。

呢兩單意外都同大雨有關，亦都顯示雨季期間排水渠、河道同山坡周邊嘅危險性。

**俾旅客嘅提醒：**

如果聽日準備由機場去Kuta、Legian或者Seminyak，建議出發前check清楚道路狀況，同埋預多啲交通時間。

雨季喺峇里島揸車，最需要避免嘅唔係落雨本身，而係低估積水、河水暴漲同山坡山泥傾瀉嘅風險。遇到積水路段，唔好冒險涉水通過。

## ✈️ Jember直飛峇里島航線11月27日恢復！Wings Air每週飛兩班

印尼東爪哇Jember同峇里島之間嘅直飛航班就快恢復，對計劃結合東爪哇同峇里島旅行嘅旅客嚟講，係一個值得留意嘅交通消息。

根據Jember交通局11月23日公布嘅消息，Wings Air會由2026年11月27日起，重新營運Jember至峇里島嘅航線。

航班資料如下：

| 項目 | 資訊 |
| --- | --- |
| 航空公司 | Wings Air |
| 航線 | Jember（JBB）－Denpasar（DPS） |
| 開始日期 | 2026年11月27日 |
| 班次 | 每週一、週五 |
| 機型 | ATR 72-500／ATR 72-600 |
| 飛行時間 | 約1小時20分鐘 |

參考時間：

- 峇里島飛去Jember：08:05 WITA起飛
- Jember飛返峇里島：09:00 WIB起飛

而家公佈嘅起步票價係：

- Jember → 峇里島：IDR 640,000起
- 峇里島 → Jember：IDR 761,000起

實際票價會根據出發日期同座位供應而變動。

呢條航線之前喺2025年12月開通過，但因為航空燃油成本上升，喺2026年5月暫停營運，今次配合聖誕節同新年假期重新啟用。

對峇里島旅客嚟講，呢個都增加咗安排東爪哇旅行嘅可能性。Jember周邊可以延伸探索Papuma Beach、Watu Ulo Beach同周邊自然景點。

如果已經喺峇里島旅行，想順便去東爪哇，將來可以多一個唔使長途搭汽車同渡輪嘅選擇。

## 🏌️ Handara Golf & Resort連續兩年攞亞洲最佳環保高爾夫設施！Bedugul高原度假再受國際關注

位於峇里島Bedugul高原嘅Handara Golf & Resort Bali，再次獲得World Golf Awards 2026嘅Asia's Best Eco-Friendly Golf Facility獎項，連續兩年得到同樣嘅肯定。

呢個獎項肯定咗度假村喺環境保護同可持續發展方面嘅努力，今年亦啱啱係Handara成立50週年。

Handara表示，目前推行嘅環保措施包括：

- 節約同管理水資源
- 減少垃圾同一次性塑膠使用
- 推動Micro Farm同Farm to Table
- 使用本地農產品同供應商
- 加強同當地社區嘅合作

度假村亦表示，大約90%嘅員工同高爾夫球場球僮嚟自周邊地區，並同16間本地供應商合作。

Handara喺Bedugul高原，周圍氣候比較涼爽，同峇里島南部海岸型度假村好唔同。

鍾意高爾夫、山區度假同自然環境嘅旅客嚟講，呢個消息令Handara再次引起國際旅遊市場嘅關注。

不過，呢個係設施同可持續發展方面嘅行業獎項，並唔代表住宿質素排名或者價格保證，實際預訂仲要參考房型、設施同近期旅客評價。
