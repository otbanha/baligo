# **峇里島最新新聞｜11月27日：極端天氣警報、網約車新規與北峇里島生態文化節**

峇里島就嚟到11月底，雨季天氣會明顯變差。BMKG最新警告，11月27日至30日全島可能會落中雨到極大雨，部分海域浪高仲可能去到2.5米。

交通方面，峇里島已經正式實施新嘅網約租車管理法規，包括車輛年期、司機資格同平台營運規定。另外，北峇里島呢個週末有生態文化節，Kuta亦會舉辦國際刺青藝術展。

## **🌧️ BMKG警告11月27日至30日極端天氣！全島留意豪雨、強風同土石流**

印尼氣象、氣候同地球物理局（BMKG）第三區氣象中心喺11月26日發布最新警告，提醒峇里島居民同旅客，11月27日至30日可能會出現較強嘅降雨同強風。

BMKG指出，近期大氣環流有變化，包括氣流輻合、Madden-Julian Oscillation（MJO）同赤道羅斯貝波（Equatorial Rossby Wave）等因素，都可能令峇里島嘅降雨強度增加。

**11月27日全島天氣概況：**

| 項目 | 預報 |
| --- | --- |
| 整體天氣 | 中雨 |
| 氣溫 | 22–33°C |
| 相對濕度 | 65–98% |
| 風向 | 東風至西南風 |
| 風速 | 4–30公里／小時 |
| 北部海域浪高 | 0.25–1米 |
| 南部海域浪高 | 0.25–2米 |

**11月27日至30日特別警戒：**

BMKG提醒，峇里島九個縣市同城市都可能出現中雨至極大雨同強風，包括：

- Badung巴東
- Denpasar登巴薩
- Gianyar吉安雅
- Tabanan
- Bangli
- Buleleng布勒倫
- Jembrana珍布拉娜
- Klungkung克隆孔
- Karangasem卡朗阿森

可能會引發嘅災害包括：

- 道路同低窪地區水浸
- 突發性洪水（Flash Flood）
- 山區泥石流
- 樹木倒塌同強風造成嘅設施損壞

**海上活動都要特別留意。**

BMKG預警指出，11月27日至30日以下海域浪高可能達到1.25–2.5米：

- 峇里島南部海域
- 巴東海峽（Selat Badung）
- 峇里海峽南部
- 龍目海峽南部

呢個對去Nusa Penida、Nusa Lembongan同其他離島嘅旅客尤其重要。

**提提旅客：**

呢幾日安排戶外行程，建議特別留意金塔馬尼、Bedugul、瀑布同山區道路。

如果有搭船或者參加浮潛、潛水活動，出發前記得同船公司確認海況同係咪正常營運。

目前冇全島景點統一關閉嘅公告，但遇到大雨嗰陣，唔建議為咗趕行程而冒險通過積水道路或者喺惡劣海況下出海。

## **🚗 峇里島網約租車新規正式生效！車齡限制10年、排氣量至少1,000cc**

如果你喺峇里島成日用GrabCar、Gojek嘅汽車叫車服務，呢項新規值得留意。

根據Bali Post喺11月25日報導，峇里島省政府已經正式實施《2026年第8號省級法規》（Perda Provinsi Bali No. 8 Tahun 2026），規範用手機應用程式預訂嘅特殊租賃運輸服務（Angkutan Sewa Khusus，ASK）。

呢項法規其實已經喺2026年10月27日公布同生效，最近媒體再整理咗相關規定。

**車輛規格限制：**

| 項目 | 新規定 |
| --- | --- |
| 汽油／燃油車車齡 | 最多10年 |
| 最低引擎排氣量 | 1,000cc |
| 電動車最低動力 | 70kW |
| 車輛登記 | 必須喺峇里島註冊 |

**司機資格都有新要求：**

- 必須符合相關駕駛資格同法規。
- 必須具備至少6個月駕駛經驗。
- 能夠用印尼語同英語溝通。
- 峇里語能力列為優先條件。
- 必須保持良好服務態度同著得整齊。

**網約車平台都受到規範：**

- 一定要有印尼合法法人資格。
- 一定要喺峇里島開分公司。
- 一定要同攞到合法營運許可同配額嘅ASK業者合作。
- 一定要提供營運資料同數碼管理平台，俾省政府監管。

另外，法例都規定政府會設定車輛營運配額，同埋運費嘅上下限，仲會定期檢討。

**對遊客有咩影響？**

呢條法例嘅重點，係令峇里島網約車服務更加制度化，包括車輛安全、司機資格同乘客權益。

不過，而家唔可以直接話所有叫車平台都會即刻調整服務，亦都唔可以將呢個ASK汽車租賃規範直接當成GoRide呢啲電單車叫車服務嘅規則。

對旅客嚟講，最值得留意嘅係將來網約車嘅車輛規格、合法營運資格同運費管理可能會逐步改變。

而家政府仲未公布所有平台嘅實際轉換時間表，亦都冇證據顯示旅客現階段需要額外辦理任何手續。

## **🪸 北峇里島Pemuteran Bay Festival 11月27日至29日登場！免費入場、結合海洋保育同文化活動**

如果呢個週末啱啱喺峇里島北部，值得留意Pemuteran Bay Festival 2026。

呢個係一個以生態旅遊、地方文化同海洋保育為主題嘅年度活動，地點喺Buleleng縣Pemuteran村。

印尼觀光部官方旅遊入口網站目前列出嘅活動日期係11月27日至29日，仲標示免費入場。

**活動資訊：**

| 項目 | 資訊 |
| --- | --- |
| 活動名稱 | Pemuteran Bay Festival 2026 |
| 日期 | 11月27日至29日 |
| 地點 | Pemuteran, Buleleng |
| 主題 | Foresting the Ocean |
| 入場費 | 免費 |

活動內容包括：

- 峇里島傳統音樂同文化表演
- 當地美食市集
- Yoga同戶外活動
- 海洋保育講座
- 珊瑚礁復育工作坊
- Biorock珊瑚復育相關活動
- 海岸及環境保育活動

Pemuteran最值得認識嘅特色之一，就係當地長期推動嘅Biorock珊瑚復育計劃。

呢項技術透過水下金屬結構同低電壓電流，促進礦物質沉積，幫手復育珊瑚礁。Pemuteran亦因此成為印尼有代表性嘅社區型海洋保育旅遊地區。

對鍾意浮潛、潛水同自然生態嘅旅客嚟講，呢場活動唔止係一般音樂或文化節，仲可以認識當地居民點樣結合旅遊同海洋保育。

**有一點要特別提醒：活動日期曾經出現唔同版本。**

10月26日DetikBali報道曾經引用峇里島省觀光局當時嘅日曆，列出11月26日至28日；而家印尼觀光部官方活動頁面就列為11月27日至29日。

所以，如果專程由峇里島南部揸車過去，建議先向主辦單位確認最新活動安排，唔好只係靠較早嘅活動日曆。

另外，雖然活動係免費入場，潛水、浮潛、船同部分特定體驗可能仲要另外俾錢。
