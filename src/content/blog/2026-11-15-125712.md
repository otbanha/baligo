## 峇里島11月16日天氣展望：多地預測降雨，Tabanan及Bangli留意雨勢

印尼氣象、氣候及地球物理局（BMKG）最新預報顯示，2026年11月16日峇里島多個縣市可能出現降雨，整體仍處於雨季天氣型態。

根據BMKG目前的縣市預報：

| 地區 | 11月16日預測 |
| --- | --- |
| 登巴薩（Denpasar） | 多雲 |
| 巴東縣（Badung） | 小雨 |
| 吉安雅縣（Gianyar） | 小雨 |
| 克隆孔縣（Klungkung） | 多雲 |
| Tabanan | 小雨至中等降雨 |
| Bangli | 小雨 |
| 卡朗阿森（Karangasem） | 小雨 |
| 布勒倫（Buleleng） | 小雨 |
| 珍布拉娜（Jembrana） | 小雨 |

全島各地預測氣溫約19–32°C，相對濕度最高可能接近99%。

海象方面，BMKG預測峇里島北部海域浪高約0.5–1.25公尺，南部海域約1–2公尺。海況仍需依照出發當日的港口與船公司公告確認。

對旅客而言，明天如果安排烏布、Bedugul、Jatiluwih梯田或瀑布景點，建議預留天氣彈性。雨季並不代表全天降雨，但午後戶外活動可能受到局部雨勢影響。

若要前往努沙佩尼達、努沙藍夢島等離島，也建議出發前確認海況及船班。

資料：BMKG峇里島縣市預報及BBMKG Region III。

## **Sanur電動接駁巴士導入QRIS Tap！11月15日至30日優惠價68印尼盾**

峇里島的數位支付應用開始延伸至地方觀光交通。

印尼銀行峇里島分行於11月14日在沙努爾舉行的Baligivation 2026活動中，正式將QRIS及QRIS Tap支付功能導入由Desa Adat Intaran營運的電動接駁巴士。

這項服務主要在Sanur當地觀光區域運行，讓居民及旅客可以使用數位方式支付交通費。

目前接駁巴士資訊如下：

- 營運單位：Desa Adat Intaran
- 車輛數量：12輛
- 每輛容量：最多10名乘客
- 一般票價：每人5,000印尼盾
- 支付方式：QRIS及QRIS Tap

為推廣數位交易，印尼銀行及峇里島政府推出限時優惠：

優惠期間 11/15–11/30

每人每趟優惠價：Rp68

優惠價格配合峇里島省政府成立68週年的象徵數字，並設有每日名額限制。

對旅客而言，這項措施是沙努爾地方接駁交通數位化的新嘗試。不過，實際乘車路線、每日優惠名額及付款支援方式仍需以現場資訊為準。

## 峇里島與日本深化合作！觀光、投資及青年赴日就業成為重點

峇里島省長Wayan Koster希望進一步加強峇里島與日本的合作關係，並將雙方交流從外交及文化層面，推進至更具體的經濟與社會合作。

Koster提出的合作方向包括：

- 觀光產業合作
- 日本企業在峇里島的投資
- 峇里島青年赴日本工作
- 技術及職業技能培訓
- 加強地方政府與日本企業的交流

省長特別提到，峇里島的技職學校（SMK）畢業生若具備符合日本市場需求的技能，未來可以爭取更多海外就業機會。

Koster也表示，部分目前在日本工作的峇里島青年，對工作環境及收入表現給予正面評價。

不過，這次談話主要是提出合作方向，尚未公布新的正式就業計畫、招聘名額或具體投資協議。

對峇里島而言，日本不僅是重要的國際旅遊市場，也可能成為未來人才培育及產業合作的重要夥伴。

## 峇里島電力備轉率僅16.18%！電動車增加，PLN加強充電設施建設

峇里島電力需求持續增加，電力備轉容量成為近期值得關注的議題。

5MW，可供電能力為1,678MW，電力備轉率約16.18%。

這個數字僅略高於地方電力系統通常要求的15%最低備轉標準。

另一方面，峇里島電動車數量也持續成長。

截至2026年9月，峇里島登記的電動車已達18,034輛，其中：

- 電動汽車：超過6,700輛
- 電動機車：超過11,000輛

其中，2026年前9個月的電動汽車數量，相較2025年底約成長100%。

PLN峇里島分行表示，未來將持續確保供電穩定，並加強充電設施建設，以配合電動車生態系統發展。

這項消息並不代表峇里島即將發生電力短缺，而是顯示當地電力需求及能源轉型需要同步管理。

對旅客來說，如果使用電動車租賃服務，未來充電設施的分布及供電穩定性，將是影響旅遊便利性的重要因素。

## **Bangli舉行I Gusti Ngurah Rai英雄紀念旗幟巡行！明日將移交Gianyar**

峇里島Bangli縣於11月15日舉行紀念印尼民族英雄I Gusti Ngurah Rai的旗幟及歷史文書巡行活動，配合印尼11月10日Hari Pahlawan（英雄日）的紀念安排。

這次活動由Bangli縣政府主辦，巡行隊伍從Klungkung縣移交的Pataka旗幟及Ngurah Rai歷史文書開始，於Bangli市區Alun-Alun Bangli舉行交接儀式。

隨後，巡行隊伍經過Bangli多個地區，包括：

- Peninjoan
- Tembuku
- Suter
- Manikliyu
- Landih
- Pengotan
- Kintamani
- Susut
- Penglipuran英雄墓園（TMP Penglipuran）

Bangli縣長Sang Nyoman Sedana Arta表示，希望透過這項活動讓年輕一代認識I Gusti Ngurah Rai的歷史及峇里島在印尼獨立運動中的角色。

巡行活動將於11月16日繼續，並移交給Gianyar縣政府。

這項活動屬於地方歷史紀念儀式，並非專為觀光客設計的旅遊表演。如果旅客明天在Bangli或Gianyar部分道路遇到巡行隊伍，可能需要留意短暫的交通影響。
