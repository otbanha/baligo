# **峇里島最新新聞｜11月27日：極端天氣警報、網約車新規與北峇里島生態文化節**

峇里島即將迎來11月底一波較明顯的雨季天氣變化。BMKG最新警告，11月27日至30日全島可能出現中雨至極大雨，部分海域浪高也可能達到2.5公尺。

交通方面，峇里島已正式實施新的網約租車管理法規，涉及車輛年限、司機資格及平台營運規定。另外，北峇里島本週末有生態文化節，Kuta也將舉辦國際刺青藝術展。

## **🌧️ BMKG警告11月27日至30日極端天氣！全島留意豪雨、強風及土石流**

印尼氣象、氣候及地球物理局（BMKG）第三區氣象中心於11月26日發布最新警告，提醒峇里島居民及旅客，11月27日至30日可能出現較強的降雨及強風。

BMKG指出，近期大氣環流出現變化，包括氣流輻合、Madden-Julian Oscillation（MJO）及赤道羅斯貝波（Equatorial Rossby Wave）等因素，都可能增加峇里島的降雨強度。

**11月27日全島天氣概況：**

| 項目 | 預報 |
| --- | --- |
| 整體天氣 | 中雨 |
| 氣溫 | 22–33°C |
| 相對濕度 | 65–98% |
| 風向 | 東風至西南風 |
| 風速 | 4–30公里／小時 |
| 北部海域浪高 | 0.25–1公尺 |
| 南部海域浪高 | 0.25–2公尺 |

**11月27日至30日特別警戒：**

BMKG提醒，峇里島九個縣市及城市都可能出現中雨至極大雨及強風，包括：

- Badung巴東
- Denpasar登巴薩
- Gianyar吉安雅
- Tabanan
- Bangli
- Buleleng布勒倫
- Jembrana珍布拉娜
- Klungkung克隆孔
- Karangasem卡朗阿森

可能引發的災害包括：

- 道路及低窪地區淹水
- 突發性洪水（Flash Flood）
- 山區土石流
- 樹木倒塌及強風造成的設施損壞

**海上活動也需要特別注意。**

BMKG預警指出，11月27日至30日以下海域浪高可能達到1.25–2.5公尺：

- 峇里島南部海域
- 巴東海峽（Selat Badung）
- 峇里海峽南部
- 龍目海峽南部

這對前往Nusa Penida、Nusa Lembongan及其他離島的旅客尤其重要。

**給旅客的提醒：**

這幾天安排戶外行程，建議特別留意金塔馬尼、Bedugul、瀑布及山區道路。

如果有搭船或參加浮潛、潛水活動，請在出發前向船公司確認海況及是否正常營運。

目前並沒有全島景點統一關閉的公告，但遇到強降雨時，不建議為了趕行程而冒險通過積水道路或在惡劣海況下出海。

## **🚗 峇里島網約租車新規正式生效！車齡限制10年、排氣量至少1,000cc**

如果你在峇里島經常使用GrabCar、Gojek的汽車叫車服務，這項新規值得留意。

根據Bali Post於11月25日報導，峇里島省政府已正式實施《2026年第8號省級法規》（Perda Provinsi Bali No. 8 Tahun 2026），規範以手機應用程式預訂的特殊租賃運輸服務（Angkutan Sewa Khusus，ASK）。

這項法規其實已於2026年10月27日公布並生效，近期媒體進一步整理了相關規定。

**車輛規格限制：**

| 項目 | 新規定 |
| --- | --- |
| 汽油／燃油車車齡 | 最多10年 |
| 最低引擎排氣量 | 1,000cc |
| 電動車最低動力 | 70kW |
| 車輛登記 | 必須在峇里島註冊 |

**司機資格也有新要求：**

- 必須符合相關駕駛資格及法規。
- 必須具備至少6個月駕駛經驗。
- 能夠使用印尼語及英語溝通。
- 峇里語能力列為優先條件。
- 必須保持良好服務態度及穿著整潔。

**網約車平台也受到規範：**

- 必須具備印尼合法法人資格。
- 必須在峇里島設立分公司。
- 必須與取得合法營運許可及配額的ASK業者合作。
- 必須提供營運資料及數位管理平台，供省政府監督。

另外，法規也規定政府將設定車輛營運配額，以及運價上下限，並定期檢討。

**對遊客有什麼影響？**

這項法規的重點，是讓峇里島網約汽車服務更加制度化，包括車輛安全、司機資格及乘客權益。

不過，目前不能直接推論所有叫車平台都會立即調整服務，也不能將這項ASK汽車租賃規範直接等同於GoRide等摩托車叫車服務的規則。

對旅客而言，最值得注意的是未來網約車的車輛規格、合法營運資格及運價管理可能逐步改變。

目前尚未看到政府公布所有平台的實際轉換時程，也沒有證據顯示旅客現階段需要額外辦理任何手續。

## **🪸 北峇里島Pemuteran Bay Festival 11月27日至29日登場！免費入場、結合海洋保育與文化活動**

如果這週末剛好在峇里島北部，值得留意Pemuteran Bay Festival 2026。

這是一場以生態旅遊、地方文化及海洋保育為主題的年度活動，地點位於Buleleng縣Pemuteran村。

印尼觀光部官方旅遊入口網站目前列出的活動日期為11月27日至29日，並標示免費入場。

**活動資訊：**

| 項目 | 資訊 |
| --- | --- |
| 活動名稱 | Pemuteran Bay Festival 2026 |
| 日期 | 11月27日至29日 |
| 地點 | Pemuteran, Buleleng |
| 主題 | Foresting the Ocean |
| 入場費 | 免費 |

活動內容包括：

- 峇里島傳統音樂及文化表演
- 當地美食市集
- Yoga及戶外活動
- 海洋保育講座
- 珊瑚礁復育工作坊
- Biorock珊瑚復育相關活動
- 海岸及環境保育活動

Pemuteran最值得認識的特色之一，就是當地長期推動的Biorock珊瑚復育計畫。

這項技術透過水下金屬結構及低電壓電流，促進礦物質沉積，協助珊瑚礁復育。Pemuteran也因此成為印尼具有代表性的社區型海洋保育旅遊地區。

對喜歡浮潛、潛水及自然生態的旅客而言，這場活動不只是一般音樂或文化節，也能認識當地居民如何結合觀光與海洋保育。

**有一點需要特別提醒：活動日期曾出現不同版本。**

10月26日DetikBali報導曾引用峇里島省觀光局當時的日曆，列出11月26日至28日；目前印尼觀光部官方活動頁面則列為11月27日至29日。

因此，若專程從峇里島南部開車前往，建議先向主辦單位確認最新活動安排，不要只依據較早的活動日曆。

另外，雖然活動免費入場，潛水、浮潛、船隻及部分特定體驗仍可能需要另外付費。

## **🎨 Kuta國際刺青藝術展11月27日至29日登場！國際刺青師齊聚，最高獎金5,000萬印尼盾**

本週末Kuta還有一場比較特殊的國際活動：Island of Gods International Tattoo Convention 2026。

這是峇里島首次舉辦的國際刺青展會，將邀請來自印尼、馬來西亞、新加坡、越南、菲律賓、澳洲、希臘、美國及韓國等地的刺青藝術家及工作室參與。

**活動資訊：**

| 項目 | 資訊 |
| --- | --- |
| 活動名稱 | Island of Gods International Tattoo Convention |
| 日期 | 11月27日至29日 |
| 時間 | 10:00–22:00 |
| 地點 | Discovery Kartika Plaza Hotel |
| 地址 | Jl. Kartika Plaza, Kuta |
| 最高獎金 | IDR 50,000,000 |

三天活動都有不同的現場刺青比賽：

- **11月27日：** Fine Line、Black & Grey、Anime、Small Tattoo等。
- **11月28日：** Japanese／Asian、Neo Traditional、大型彩色及黑灰刺青等。
- **11月29日：** Realism、Ornamental、Blackwork、Collaboration，以及最終的Best of Show。

其中Best of Show冠軍可獲得5,000萬印尼盾獎金，以及專門製作的藝術獎盃。

活動除了現場刺青及比賽，也包括藝術展示、座談、峇里島傳統文化表演及現場音樂。

對刺青文化、人體藝術及國際創意產業有興趣的旅客，可以將這場活動列入週末參觀選項。

活動採電子票券入場，購票後需在現場兌換手環作為入場憑證。實際票價及購票條件以官方售票頁面為準。
