# 峇里島最新新聞｜11月23日：雨季天氣、外國遊客海上救援與北峇里島郵輪旅遊

峇里島11月22日的最新旅遊消息，除了雨季天氣及海況提醒，還有一起涉及3名外國遊客的海上救援事件。另外，北峇里島Buleleng的旅遊人次持續增加，當地預計12月將迎接約5艘郵輪，為年底旅遊旺季帶來新的客源。

## 🌦️ 11月23日峇里島天氣：部分地區有雨，南部海域浪高達2.5公尺

BMKG峇里島省最新縣市預報顯示，11月23日峇里島各地以多雲及局部小雨為主，Tabanan、Klungkung、Bangli及Buleleng預測有小雨，其餘地區大致多雲。

**各地天氣預報：**

| 地區 | 天氣 | 氣溫 |
| --- | --- | --- |
| Denpasar登巴薩 | 多雲 | 25–32°C |
| Badung巴東 | 多雲 | 25–33°C |
| Gianyar吉安雅 | 多雲 | 24–31°C |
| Tabanan | 小雨 | 23–28°C |
| Klungkung | 小雨 | 25–32°C |
| Bangli | 小雨 | 20–26°C |
| Karangasem卡朗阿森 | 多雲 | 22–30°C |
| Buleleng布勒倫 | 小雨 | 25–30°C |
| Jembrana珍布拉娜 | 多雲 | 24–30°C |

另外，BMKG先前發布的降雨警報涵蓋Badung、Bangli、Buleleng、Gianyar、Jembrana及Tabanan，預警時段至11月23日上午8時（峇里島時間）。Badung、Karangasem及Buleleng也曾被列入強風提醒區域。

**海象方面更值得注意：**

BMKG於11月22日發布的海浪預警，有效期至11月25日上午8時，峇里島周邊5個海域列入中等浪高警戒，預測浪高為1.25–2.5公尺，包括：

- 峇里島南部海域
- 巴東海峽（Selat Badung）
- 峇里島海峽南部
- 龍目海峽南部
- 龍目海峽北部

對旅客而言，這幾天前往努沙佩尼達、努沙藍夢島及其他離島，建議事先確認船公司是否正常營運。前往山區及瀑布景點，也要留意降雨後的道路濕滑情況。

## 🚨 3名外國遊客從爪哇搭乘水上摩托車前往峇里島，途中故障受困海上

11月21日上午，3名外國遊客從東爪哇Banyuwangi的Alas Purwo出發，準備搭乘水上摩托車（Jetski）前往峇里島Jimbaran，途中卻發生機械故障，受困於Uluwatu外海。

根據印尼國家搜救局（Basarnas）公布的資料，3人分別為：

- 2名印度籍旅客
- 1名荷蘭籍旅客

當天上午約7時，3人分乘兩輛Jetski出發，約一小時後，其中一輛發生引擎故障，無法繼續航行。

上午8時30分左右，相關人員向Denpasar搜救中心求助。

Basarnas隨即派出KN SAR Arjuna 229及橡皮艇（RIB）前往搜尋，上午9時45分成功找到3人，當時所有人均平安。

救援隊隨後將3人送往Benoa港口。

Basarnas負責人I Nyoman Sidakarya表示，這3名旅客原本住在北龍目島，獲救後預計先修理Jetski，再繼續前往龍目島。

他也提醒民眾，進行長距離海上活動前，必須確認自身體力、交通工具狀況、安全裝備及通訊設備是否正常。

**給旅客的提醒：**

這次事故雖然沒有造成人員傷亡，但也提醒大家，水上摩托車並不適合在沒有完善準備的情況下進行長距離跨海移動。

如果參加峇里島的Jetski活動，應選擇有正式營運安排的業者，並確認：

- 是否提供救生衣及必要安全裝備
- 是否有工作人員陪同或安全支援
- 活動範圍及允許航行距離
- 出發前是否確認海況及機械狀況

## 🚢 北峇里島旅遊人次達177萬！12月預計迎接5艘郵輪停靠Celukan Bawang

峇里島北部Buleleng縣的觀光市場持續成長，當地政府希望利用年底聖誕節及新年假期，吸引更多國內外旅客前往北峇里島。

根據Bali Post於11月22日報導，Buleleng縣政府公布，截至11月下旬，2026年累計旅客人次已達：

**1,775,068人次**

相較2025年公布的1,706,796人次，增加約4.05%。

Buleleng觀光單位表示，年底將透過與飯店及旅遊業者合作，推出旅遊套裝產品，並加強推廣當地景點。

其中一個值得注意的發展，是國際郵輪旅遊。

當地預計2026年12月將有約5艘郵輪停靠Celukan Bawang港口。

目前公布的預估靠港時間為：

- 抵達時間：約上午8時
- 離港時間：約下午4時
- 停靠地點：Pelabuhan Celukan Bawang
- 旅遊安排：由郵輪旅行社提供當地套裝觀光行程

郵輪旅客停留期間，將依照旅行社安排前往Buleleng周邊景點。

**北峇里島有哪些值得旅遊的地方？**

Celukan Bawang位於Buleleng縣，周邊可延伸探索：

- Lovina：以海豚觀賞及海濱住宿聞名
- Gitgit：北峇里島瀑布景點
- Pemuteran：潛水、浮潛及海洋保育旅遊
- Bali Aga村落：認識峇里島傳統村落文化
- Bedugul：湖泊、山區景觀及寺廟

不過，這5艘郵輪目前仍屬當地政府的預估安排，尚未公布每艘船的確切停靠日期。

對一般自由行旅客而言，郵輪旅遊增加代表北峇里島的國際曝光度正在提高，也讓旅客有更多理由探索峇里島南部以外的地區。
