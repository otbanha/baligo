## **🌦️ 峇里島11月17日天氣展望：多地有雨，南部海域浪高可能達2.5公尺**

印尼氣象、氣候及地球物理局（BMKG）峇里島第三區氣象中心最新預報顯示，2026年11月17日峇里島整體以多雲天氣為主，但部分地區仍有降雨及雷雨可能。

根據BMKG公布的天氣資訊：

| 項目 | 11月17日預報 |
| --- | --- |
| 全島概略氣溫 | 19–34°C |
| 相對濕度 | 65–90% |
| 風向 | 東至南風 |
| 風速 | 約3–30公里／小時 |
| 峇里島北部海域浪高 | 0.5–1.25公尺 |
| 峇里島南部海域浪高 | 0.5–2.5公尺 |

各地降雨情況也有所不同：

- 登巴薩：小雨，約25–32°C
- Badung巴東縣：可能出現雷雨，約24–31°C
- Gianyar吉安雅縣：小雨，約23–29°C
- Bangli：小雨，約19–27°C
- Tabanan：小雨，約22–27°C
- Buleleng布勒倫：小雨，約24–30°C

BMKG提醒，峇里島部分地區可能出現伴隨雷電的中等降雨，南部海域也可能有2公尺以上浪高，特別是峇里島南部海峽、Badung海峽及南部海域。

對旅客而言，明天若安排戶外景點、瀑布或山區旅行，建議預留行程彈性。前往努沙佩尼達、努沙藍夢島等離島時，也應確認船公司及港口的最新海況資訊。

雨季並不代表整天都會下雨，但局部雨勢可能影響道路交通及海上活動。

## **🏥 Sanur醫療觀光特區累計投資達5.76兆印尼盾！創造近6,000個工作機會**

位於沙努爾的Sanur Special Economic Zone（KEK Sanur）公布最新投資成果。截至2026年第三季，該特區自2023年以來累計實現投資達5.76兆印尼盾，約合3.15億美元。

根據印尼經濟統籌部於11月16日公布的資料：

- 累計投資：5.76兆印尼盾
- 累計創造工作機會：5,911個
- 進駐企業：15家
- 2026年前三季新增投資：5,158.7億印尼盾
- 2026年全年投資目標：1.25兆印尼盾
- 第三季累計病患人次：36,798人

其中，外國病患達22,046人次，印尼國內病患則為14,752人次。

Sanur醫療觀光特區是印尼第一個以健康及醫療觀光為核心的特別經濟區，主要希望吸引國際病患，並降低印尼民眾赴海外就醫所產生的外匯流出。

目前Bali International Hospital已於2025年4月14日開始營運，提供心臟科、腫瘤科、神經科、腸胃科、婦產科及骨科等專科服務。

此外，Alster Lake Clinic及The Solitaire Clinic也已開始營運，其他醫療設施仍在發展中。

對峇里島而言，Sanur未來不只是傳統海濱度假區，也可能逐步發展成為醫療觀光及健康產業的重要據點。

不過，投資額及病患人次的成長，仍不代表所有醫療設施均已全面完成或開放。

## **🚦 峇里島啟動Operasi Zebra Agung 2026！外國旅客交通違規也將依法取締**

峇里島警方於11月16日啟動Operasi Zebra Agung 2026交通安全執法行動，目標是降低交通違規、事故及事故死亡人數。

峇里島警方表示，此次行動共投入1,067名警力，其中包括：

- 峇里島省警察總局：263人
- 各縣市警察單位：804人

警方指出，2026年1月至9月期間，峇里島交通事故死亡人數從2025年同期的404人增加至415人；輕傷人數則從7,572人增加至9,581人。

另一方面，重傷人數從66人下降至52人。

警方表示，Operasi Zebra Agung除了執法，也將加強交通安全宣導，並為年底聖誕節及新年假期（Nataru）的交通管理提前準備。

此次行動並不區分印尼居民或外國旅客，所有道路使用者均須遵守交通規則。

對峇里島旅客來說，近期租用機車或自行駕駛時，建議特別留意：

- 必須持有符合印尼規定的駕照
- 騎乘機車時佩戴安全帽
- 不可逆向或危險超車
- 不可酒後駕駛
- 遵守道路標誌及交通號誌

警方也表示，電子交通執法（ETLE）及人工開單的執法量較2025年增加24%。

這項行動是交通安全執法，不代表峇里島所有道路都會設置固定檢查站；實際執法地點將依警方每日評估調整。

## **🏛️ Gajah Mada歷史街區暫停部分施工！Secondary Skin立面設計重新檢討**

登巴薩市政府於11月16日宣布，暫停市中心Jalan Gajah Mada歷史街區部分建築立面工程（Secondary Skin）的施工。

這項決定主要是回應民眾對設計的意見，同時進行工程品質及整體街區風格的檢討。

登巴薩市公共工程及空間規劃局（PUPR）表示，暫停施工預計持續數日，讓相關單位重新檢視立面設計是否符合歷史街區的建築特色。

此次街區整體規劃涉及：

- Jalan Gajah Mada
- Jalan Sumatera
- Jalan Hasanuddin
- Jalan Thamrin

這些區域除了商業活動，也包含宗教場所及不同族群的社區生活空間。

市政府表示，暫停的只是部分Secondary Skin立面施工，其他工程項目仍會持續進行，以維持原定的工程進度。

對旅客而言，Jalan Gajah Mada是登巴薩市中心具有歷史及商業特色的區域。若近期安排前往市區觀光或購物，可以留意現場施工狀況。

目前官方並未宣布整條街區封閉，因此不宜將這次工程暫停理解為全面道路封閉。

## **💰 Gianyar完成2027年度預算草案議會程序！地方收入目標達2.47兆印尼盾**

Gianyar縣政府與地方議會於11月16日完成2027年度地方預算草案（APBD 2027）的議會決議程序，並將提高地方自主收入（PAD）列為重要方向。

根據ANTARA報導，Gianyar縣長Made Mahayastra表示，2027年度地方財政將在收入有限的情況下，持續支應公共服務及地方建設。

預算主要數字如下：

| 項目 | 2027年預算規劃 |
| --- | --- |
| 地方總收入 | 3.75兆印尼盾 |
| 地方自主收入（PAD） | 2.47兆印尼盾 |
| 中央及其他轉移收入 | 1.27兆印尼盾 |
| 地方總支出 | 3.69兆印尼盾 |
| 預計盈餘 | 608億印尼盾 |

其中，地方自主收入目標較2026年度增加815億印尼盾，成長約3.40%。

Gianyar地方議會也提出，未來應透過地方稅務及規費數位化，提升收入管理效率，並將基礎建設支出優先配置於符合居民需求的項目。

此外，這次會議也通過包括人口行政、地方創新、住宅及居住區、建築工程、環境保護與災害管理等6項地方規範草案。

需要注意的是，2027年度預算草案完成地方議會程序後，仍需提交峇里島省長進行評估，後續才進入正式核定程序。

對旅客而言，這項預算並非立即生效的新旅遊稅或住宿費調整，而是Gianyar縣明年度地方財政及建設方向的規劃。
