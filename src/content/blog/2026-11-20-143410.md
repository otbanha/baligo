# 峇里島最新新聞｜11月21日：雨季天氣、Kuta海灘垃圾、卡達航空增班提案

峇里島11月20日的旅遊消息，主要集中在雨季帶來的海岸環境變化、國際航空連結及週末活動。Kuta海岸近期出現大量海漂垃圾，Badung縣已累計清除約200噸；另一方面，卡達駐印尼大使提出增加Qatar Airways直飛峇里島班次的構想，未來有望進一步改善中東旅客的交通便利性。

## 🌦️ BMKG預測11月21日多雲！中南部及東部留意雷雨，南部海域浪高可能達2公尺

印尼氣象、氣候及地球物理局（BMKG）峇里島第三區氣象中心公布11月21日最新預報，峇里島整體以多雲為主，但中部、南部及東部地區仍須留意中至大雨及雷電。

**全島天氣概況：**

| 項目 | 11月21日預報 |
| --- | --- |
| 天氣 | 多雲，局部降雨 |
| 氣溫 | 20–34°C |
| 相對濕度 | 60–95% |
| 風向 | 東至南風 |
| 風速 | 4–37公里／小時 |
| 北部海域浪高 | 0.25–1公尺 |
| 南部海域浪高 | 1–2公尺 |

BMKG特別提醒，中部、南部及東部可能出現中至大雨，並伴隨雷電。南部海域也有浪高達2公尺或以上的可能。

各地預報方面，Gianyar可能出現中等降雨，Badung、Tabanan、Denpasar及其他地區則仍須留意局部降雨。

**對旅客的影響：**

- 烏布、金塔馬尼及Bedugul等地，建議準備雨具。
- 瀑布、梯田及山區景點，出發前應確認天氣與現場狀況。
- 前往努沙佩尼達、努沙藍夢島的旅客，應確認船公司最新海況及船班。
- 海邊活動及水上運動應依照現場安全指示，不要因為岸邊看起來平靜就忽略海況。

目前並沒有全島景點統一關閉的公告，旅客不必因為進入雨季就取消所有戶外活動，但建議行程保留彈性。

## 🏖️ Kuta海灘出現大量海漂垃圾！Badung自11月5日已清除200噸

峇里島西南部海岸開始受到西風季節影響，Kuta及Badung其他海岸近期出現大量隨海流漂上岸的垃圾，當地清潔單位已加強清理工作。

根據detikBali於11月20日報導，Badung縣環境與清潔局（DLHK）自2026年11月5日起，已在各海岸地區累計清除約200噸海漂垃圾。

當局指出，這波垃圾增加與西風季節（Musim Angin Barat）及海流變化有關。

目前清理的垃圾主要包括：

- 大型木頭及樹枝
- 竹子及樹葉
- 海上漂流而來的有機物
- 塑膠瓶及一次性包裝

為了加快清理速度，Badung縣將海岸分成5個清潔作業區，並投入20輛垃圾車及2台大型裝載機，將海漂垃圾集中運走。

木材類垃圾會送往Mengwitani垃圾處理設施進行粉碎處理，其他殘餘垃圾則送往Suwung區域垃圾掩埋場。

**對旅客的影響：**

這是每年雨季前後峇里島西岸常見的季節性現象，尤其Kuta、Legian及周邊海岸可能受到海漂垃圾影響。

如果這幾天打算安排Kuta海灘散步、日落拍照或海邊活動，建議不要預設所有海灘都會維持乾淨的狀態。

這並不代表Kuta海灘全面關閉，而是部分海岸可能出現垃圾堆積及清潔車輛作業，實際情況會隨海流及清理進度改變。

## ✈️ 卡達大使提議每日增加2至3班直飛峇里島航班！Qatar Airways有望擴大運能

峇里島與中東地區的航空連結可能進一步加強。

卡達駐印尼大使H.E. Dr. Sultan bin Mubarak Saad Al-Dosari於11月19日拜會峇里島省長Wayan Koster，提出增加Qatar Airways直飛峇里島的航班頻率，希望進一步吸引卡達及中東地區旅客。

大使表示，峇里島在卡達及中東旅遊市場具有相當吸引力，但隨著旅客需求增加，也需要提升航空運能。

他提出的構想是：

**每日增加2至3班直飛航班。**

大使也表示，已就相關事項與印尼交通部進行協調，並希望繼續與峇里島政府溝通。

峇里島省長Wayan Koster對這項提議表示支持，認為增加國際航班有助於提升旅遊連結及經濟合作。

對台灣、香港及新加坡旅客而言，這項消息也值得留意。中東航線不只是服務當地旅客，也是部分歐洲旅客前往峇里島的重要轉機通道。

不過，目前這仍是增加航班的提議，並不是已經確認的增班計畫，尚未公布新增班次的正式時程、票價或實際營運日期。

| 日期 | 活動 |
| --- | --- |
| 11月21日（六） | 21K Cross Country、Squad Race、Kids Dash |
