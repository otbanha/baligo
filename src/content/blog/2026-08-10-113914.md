# 印尼QRIS是什麼？2026峇里島旅遊「無現金支付」完全解析

到峇里島旅行，你一定會在路邊攤、超商、按摩店，甚至海灘俱樂部的櫃檯上，看到一張印著彩色方塊圖案的小卡片，旁邊寫著「QRIS」。這其實是印尼全國統一的行動支付QR Code標準，也是這幾年當地人消費習慣快速改變的關鍵。這篇文章就來完整說明QRIS是什麼、台灣旅客能不能直接掃碼付款，以及在峇里島實際可行的無現金支付方式。

![raw-image](https://images.gobaligo.id/images/2026-08/1786361369033-kjc6my8wmxwkk4flysvvmmknrmekbidltfkklf1y.png)

## QRIS到底是什麼？

QRIS全名是「Quick Response Code Indonesian Standard」，由印尼央行（Bank Indonesia）在2019年推出，目的是統一境內原本各自為政的行動支付QR碼。在QRIS出現以前，GoPay、OVO、DANA等電子錢包各有各的付款碼，店家常常要貼出一整排QR碼供不同用戶掃描，非常混亂。QRIS上線後，商家只需要一組QR碼，不管消費者用哪一家App，都能掃同一組碼完成付款——概念上跟台灣現在推廣的TWQR相當類似。

這個系統普及的速度相當驚人。根據印尼央行公布的資料，截至2026年第一季，QRIS交易量年增率已經超過133%，光是峇里島當地使用QRIS的商家就超過110萬家，用戶數突破115萬人。從路邊的Nasi Goreng攤販到連鎖超商Indomaret、Alfamart，幾乎都已經支援QRIS掃碼付款。

## 台灣旅客能直接用手機掃QRIS付款嗎？

這是很多人最想知道的問題，答案是：**目前還不行**。

印尼央行近年積極推動「QRIS跨境（QRIS Antarnegara / QRIS Cross-border）」計畫，讓部分國家的旅客可以直接用自己國家的行動支付App，掃描印尼當地的QRIS碼付款，反之亦然。截至2026年中，已經正式開通的合作國家包括泰國、馬來西亞、新加坡、日本、南韓與中國，印尼央行也正在與沙烏地阿拉伯、印度進行跨境QRIS的試點。

不過，台灣目前並不在這份合作名單之中，所以像LINE Pay、街口支付等台灣常用的行動支付App，暫時沒辦法直接掃描峇里島店家的QRIS碼結帳。想在峇里島用手機無現金消費，還是需要透過當地的電子錢包來完成。

## 峇里島實際可行：申辦當地電子錢包

![raw-image](https://images.gobaligo.id/images/2026-08/1786361435327-2024_11_11_157146_1731331014._large.jpg)

▲QRIS除了可以在所有的超市、便利商店使用，越來越多的商店，甚至是路邊小販都可以使用

好消息是，申辦印尼在地電子錢包完全不難，用台灣手機門號就能註冊，而且幾乎都能掃QRIS消費。目前最主流的三個選擇是GoPay、DANA、OVO：

- **GoPay**：附屬於超級App Gojek，除了付款,還能叫車、叫外送，是外國旅客最常用的入門選擇，註冊門檻也最低。不過要注意，GoPay目前不開放外國信用卡直接綁定儲值，主要儲值方式是到Indomaret、Alfamart等超商用現金儲值，或請Gojek司機協助代儲。部分教學也提到可用海外金融卡（Debit Card）免手續費儲值，但實際能否成功因發卡銀行而異，建議抵達後現場測試小額儲值。
- **DANA**：對外國旅客較友善的一點是,可以直接綁定Visa或萬事達卡的外卡進行QRIS付款，不需要印尼當地身分證（KTP），流程相對單純。
- **OVO**：同樣支援QRIS付款，但部分進階功能有時需要當地身分驗證，適合作為備用選項。

實務上,建議主力使用GoPay（因為叫車、外送、付款一站搞定），再另外準備DANA作為刷卡付款的備援，現金也保留一些小額，因為部分小型商家偶爾仍只收現金。

## 使用QRIS消費的基本流程

1. 打開電子錢包App（以GoPay為例）
2. 點選「掃描」或「Scan QR」功能
3. 對準店家桌上或收銀台的QRIS碼
4. 確認商家名稱與金額無誤後,輸入密碼或指紋完成付款
5. 螢幕出現付款成功畫面即完成,不需簽名或額外手續

![raw-image](https://images.gobaligo.id/images/2026-08/1786361812303-banner_news_qris_edc_fe1cee70f3.jpg)

QRIS付款沒有最低金額限制，即使是台幣一元的小額消費也能使用，這也是為什麼連路邊攤販都願意申請QRIS的原因。

## 使用QRIS時的注意事項

- **付款前務必核對商家名稱**：QRIS碼一般會顯示收款商家名稱，付款前先確認名稱與眼前店家相符，避免掃到錯誤或偽造的QR碼。
- **金額務必自行輸入或核對**：多數QRIS為「動態碼」，掃描後App會自動帶出金額，但仍建議付款前再次確認金額是否正確。
- **保留付款成功畫面**：偶爾網路不穩定會導致扣款狀態不明，建議保留交易紀錄截圖，方便日後對帳。
- **App儲值餘額控管**：因為儲值後餘額多半綁定在App內,建議依當次旅程需求少量多次儲值,避免帳戶內留存過多餘額。

## 常見問題

**Q：一定要用印尼電子錢包才能消費嗎，信用卡不能用嗎？** 峇里島市區的飯店、餐廳、購物中心多半仍可直接刷卡（Visa／Mastercard），QRIS主要是解決小型商家、路邊攤、傳統市場這類過去只能收現金的消費場景，兩種方式可以互相搭配使用。一般可以刷卡的商店一定可以使用QRIS；可以使用QRIS的商店不一定可以刷卡。

**Q：儲值會被收手續費嗎？** 超商現金儲值一般會有小額手續費，實際費率依App與儲值管道而異，儲值前可在App內確認當下費用說明。

**Q：QRIS未來會開放台灣直接跨境支付嗎？** 印尼央行的QRIS跨境合作名單仍在持續擴增中，近期陸續新增日本、南韓、中國,並試點沙烏地阿拉伯與印度，是否納入台灣仍需留意官方後續公告。

## 結語

QRIS已經成為峇里島當地消費的主流方式，即使台灣旅客暫時無法直接用本地App跨境掃碼付款，只要提前申辦GoPay或DANA,搭配現金與信用卡三種方式交叉使用，就能在峇里島輕鬆應付從路邊小吃到高級餐廳的各種消費場景，不必再擔心身上現金不夠或找零麻煩的問題。
