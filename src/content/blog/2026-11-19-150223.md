# **峇里島最新新聞｜11月20日：雨季豪雨警戒、機場航班異動與景點開放資訊**

11月19日值得國際旅客注意的消息，主要集中在雨季天氣、航空交通及景點開放狀況。BMKG最新預警指出，峇里島部分地區可能出現豪雨；Ngurah Rai國際機場前一天下午也發生停電，影響4班國際航班。

## **🌧️ BMKG發布豪雨警報！4個縣可能出現強降雨，南部海域浪高達2公尺以上**

印尼氣象、氣候及地球物理局（BMKG）峇里島第三區氣象中心於11月18日發布最新天氣警報，提醒11月19日至20日期間，峇里島部分地區可能出現中至強降雨，部分地區達到豪雨警戒等級。

根據氣象預報，11月19日至20日的警戒區域包括：

豪雨警戒

- Badung（巴東縣）
- Bangli
- Buleleng（布勒倫）
- Tabanan

其他地區則需留意中等強度降雨，包括登巴薩、Gianyar、Jembrana、Karangasem及Klungkung。

**11月20日整體天氣預報：**

| 項目 | 預測 |
| --- | --- |
| 天氣 | 中等降雨，局部可能較強 |
| 氣溫 | 20–32°C |
| 相對濕度 | 65–95% |
| 風向 | 東至南風 |
| 風速 | 4–37公里／小時 |
| 北部海域浪高 | 0.25–1公尺 |
| 南部海域浪高 | 1–2公尺 |

BMKG另外提醒，峇里島南部海域及南龍目海峽部分區域，可能出現2公尺或以上浪高。

這項海浪警報預計持續至11月22日上午8時（峇里島時間）。

**對旅客的影響：**

- 烏布、金塔馬尼及Bedugul等山區，應留意降雨及道路濕滑。
- 前往瀑布、梯田及戶外自然景點，建議出發前確認景區是否正常開放。
- 前往努沙佩尼達、努沙藍夢島及其他離島，應向船公司確認最新海況。
- 若遇到雷雨，不建議繼續進行海上活動或山區戶外活動。

## **✈️ Ngurah Rai國際機場停電！4班國際航班延誤，電力已恢復**

11月18日下午，峇里島Ngurah Rai國際機場國際航廈發生電力供應異常，造成部分旅客服務受到影響。

根據機場管理單位公布的資料，停電時間約從下午3時45分至5時，持續約75分鐘。

這次事件影響4班國際出境航班，平均延誤約30分鐘：

| 航空公司 | 航班編號 | 航線 |
| --- | --- | --- |
| AirAsia | AK-377 | 峇里島－吉隆坡 |
| Malaysia Airlines | MH-850 | 峇里島－吉隆坡 |
| EVA Air | BR-256 | 峇里島－台北 |
| Indonesia AirAsia | QZ-536 | 峇里島－墨爾本 |

機場方面表示，國際航廈電力已於下午5時左右恢復正常，國內航廈沒有受到影響，整體航班營運也沒有全面中斷。

至於停電原因，PLN初步指出，供應國際航廈的其中一條電力饋線出現負載下降情況，可能是造成異常的原因，目前仍須進一步確認。

機場管理單位已向受影響旅客提供飲料、點心及現場協助，並對此次事件造成的不便致歉。

**給旅客的提醒：**

目前電力已恢復，不代表後續航班一定會受到影響。不過，如果今天或近期準備從峇里島搭乘國際航班，建議：

- 出發前確認航空公司最新航班狀態。
- 不要只依賴第三方航班追蹤網站。
- 預留足夠的機場報到時間。
- 如需機場服務資訊，可聯絡InJourney Airports客服172。

## **🏛️ Klungkung峇里島文化中心11月15日起暫停開放！施工期間不接待一般訪客**

位於Klungkung縣的Pusat Kebudayaan Bali（峇里島文化中心）已於2026年11月15日起暫停對外開放，直到營運單位另行公告。

根據相關通知，這次暫停開放是為了配合文化中心後續建設工程，並確保施工期間民眾及訪客的安全。

這項工程由PT Pusat Kebudayaan Bali負責推動，整體計畫預算約1.3兆印尼盾，採多年期工程，預計2027年12月完成。

未來這座文化園區預計將成為峇里島大型文化及藝術活動的重要場地，甚至可能承接目前在登巴薩Art Centre舉辦的部分Pesta Kesenian Bali活動。

目前已確認的開放資訊：

- 暫停開放日期：2026年11月15日起
- 重新開放日期：尚未公布
- 暫停原因：後續建設工程及施工安全
- 適用範圍：Klungkung的峇里島文化中心園區

需要特別區分的是，這裡指的是Klungkung的Pusat Kebudayaan Bali，並不是登巴薩的Taman Budaya Art Centre，兩者是不同的文化設施。
