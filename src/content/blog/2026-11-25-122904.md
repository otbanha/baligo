# 峇里島最新新聞｜11月26日：雨季天氣、吉隆坡新航線與年底物價警戒

峇里島11月25日的旅遊消息，除了雨季天氣及海況提醒，航空交通也有新發展。TransNusa宣布12月起開通峇里島直飛吉隆坡航線，讓旅客有更多東南亞轉機及多國旅遊選擇。

另一方面，印尼央行開始警告年底假期可能帶來物價上漲壓力，峇里島移民局也公布一起涉及外國人的跨國假投資案件。

## 🌦️ 11月26日峇里島天氣：中部及東部部分地區有雨，南部海域浪高約2.1公尺

印尼氣象、氣候及地球物理局（BMKG）11月25日更新峇里島各縣市天氣預報，11月26日全島仍以多雲及局部降雨為主。

**11月26日各地天氣預測：**

| 地區 | 天氣 | 氣溫 |
| --- | --- | --- |
| Denpasar登巴薩 | 小雨 | 25–31°C |
| Badung巴東 | 小雨 | 24–31°C |
| Gianyar吉安雅 | 中雨 | 23–30°C |
| Tabanan | 中雨 | 22–27°C |
| Bangli | 中雨 | 19–26°C |
| Klungkung克隆孔 | 小雨 | 26–32°C |
| Karangasem卡朗阿森 | 小雨 | 20–28°C |
| Buleleng布勒倫 | 多雲 | 24–31°C |
| Jembrana珍布拉娜 | 小雨 | 22–29°C |

從預報來看，Tabanan、Gianyar及Bangli需要特別留意降雨，其他地區也不能完全排除午後降雨。

**海象方面：**

BMKG海洋氣象預報顯示，11月26日峇里島南部印度洋海域浪高約1.9至2.1公尺，屬中等浪況；峇里島海域其他部分區域則約0.8至1.2公尺。

對旅客而言，最需要注意的是離島及海上活動。

如果安排努沙佩尼達、努沙藍夢島或南部海岸水上活動，建議先向船公司確認當日海況及出航安排。

山區方面，前往烏布、金塔馬尼及Bedugul，也建議保留行程彈性，尤其是瀑布、山路及戶外活動。

目前沒有全島景點統一關閉的消息，實際狀況仍應以當地最新天氣及海況公告為準。

## ✈️ TransNusa開通峇里島直飛吉隆坡！12月10日起每週4班

峇里島與馬來西亞之間即將增加一條直飛航線。

印尼航空公司TransNusa宣布，從2026年12月10日起，正式開通峇里島登巴薩（DPS）往返吉隆坡國際機場（KUL）的直飛航班。

這是TransNusa今年從峇里島出發的第三條國際航線，之前已陸續開通普吉島及墨爾本航線。

**航班資訊：**

| 項目 | 資訊 |
| --- | --- |
| 航空公司 | TransNusa |
| 航線 | Denpasar DPS－Kuala Lumpur KUL |
| 開航日期 | 2026年12月10日 |
| 每週班次 | 4班 |
| 飛行方式 | 直飛 |

**航班時間：**

| 航班 | 出發 | 抵達 |
| --- | --- | --- |
| 8B601 | 峇里島 11:00 | 吉隆坡 14:05 |
| 8B602 | 吉隆坡 14:40 | 峇里島 18:05 |

航班時間均為當地時間。

每週營運日為星期一、四、五及日。

TransNusa也表示，這條航線將提供單一機票預訂及行李直掛服務，對從墨爾本、伯斯出發，經峇里島轉往吉隆坡的旅客特別方便。

行李方面，航空公司公布的方案包括至少20公斤免費託運行李，以及7公斤手提行李。

**對台灣及其他華語市場旅客的影響：**

這條航線不只是增加峇里島與馬來西亞之間的交通選擇，也讓安排印尼、馬來西亞及澳洲多國旅遊的旅客有更多組合。

如果原本計畫在峇里島度假後前往吉隆坡，12月10日之後可以多比較TransNusa與其他航空公司的價格及時間。

訂票前仍建議確認實際航班日期、票價、行李規定及是否符合轉機條件。

## 💰 印尼央行警告年底物價上漲壓力！聖誕新年加上2027年Galungan節慶

印尼央行峇里島代表處於11月25日提醒，峇里島年底至明年初可能面臨較大的通膨壓力。

主要原因是2026年聖誕節及新年假期（Nataru），接著又遇上2027年1月的Galungan及Kuningan傳統節慶。

這幾個時段的消費需求疊加，可能增加食品及日常用品的供應壓力。

印尼央行峇里島代表Achris Sarwani指出，峇里島常住人口約450萬至500萬人，但來自峇里島以外的旅客流量可能接近2,000萬人次，龐大的消費需求對當地物價管理構成挑戰。

**目前幾項值得注意的數字：**

| 項目 | 數據 |
| --- | --- |
| 2026年1至10月累積通膨率 | 2.74% |
| 通膨目標上限 | 3.5% |
| 剩餘目標空間 | 0.76個百分點 |
| 已執行市場平價措施 | 約377次 |

央行也指出，部分食品的現有庫存只能滿足不到兩週的需求，因此要求地方物價控制小組（TPID）加強市場供應及價格監控。

**最需要留意的期間：**

2026年12月10日至2027年1月31日，約7週。

這段時間除了聖誕節及新年旅遊旺季，也會遇到峇里島重要的Galungan及Kuningan節慶，當地食品及家庭用品需求可能進一步增加。

**對旅客的影響：**

這項警告主要針對食品及民生用品供應，並不是官方宣布旅館、機票或景點門票即將全面漲價。

不過，如果安排年底長住、租Villa自行料理，或經常在當地市場購買食材，可以多留意超市及市場價格。

另外，12月底至1月的旅遊旺季，住宿與交通仍建議提早預訂，不要等到最後一刻才安排。

## ⚠️ 峇里島移民局公布外國人假投資案件！20人涉嫌組成跨國詐騙網絡

峇里島Ngurah Rai移民局11月25日公布，近期針對外國人違規活動展開一系列執法，當中有20名外國人涉嫌參與一個針對峇里島其他外國人的跨國假投資網絡。

根據移民局負責人Muhammad Novyandri的說明，這20名外國人是在11月5日於南庫塔（Kuta Selatan）Ungasan地區的一次聯合行動中被查獲。

這起案件被列入移民局11月16日至20日執行的39名外國人遣返案件之中。

除了涉嫌假投資活動，這次移民執法也涉及其他違規情況，包括：

- 持有訪問居留許可卻從事不符合許可目的的活動。
- 逾期居留。
- 涉及其他違法或不當商業活動。
- 使用不符合規定的居留或旅行文件。

移民局表示，將持續與峇里島警方合作，加強對外國人活動的監督。

需要特別說明的是，20人的假投資案件目前應以官方公布的涉嫌及調查結果理解，不應直接將所有相關人員視為已經法院定罪。

**給在峇里島旅遊及長期居留的外國人提醒：**

如果有人透過社群媒體、私人聚會或通訊軟體向你推薦高報酬投資，尤其是聲稱有特殊管道、保證獲利或要求轉帳到私人帳戶，應先查明公司背景及合法性。

不要因為對方也是外國人，或住在峇里島的Villa、Co-working Space，就輕易相信投資邀約。

旅遊期間也應避免參與自己不了解的商業活動，以免涉及違反當地法律或簽證規定。
