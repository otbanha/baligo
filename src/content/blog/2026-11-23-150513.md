# 峇里島最新新聞｜11月24日：暴雨造成20處災情、沿海高潮警報與新航線恢復

峇里島雨季正式進入需要提高警覺的時期。11月22日晚間至23日凌晨的強降雨，已在全島造成20處災害事件，Kuta、Legian及登巴薩部分道路出現淹水，另外還發生土石流及人員死亡事故。

除了天氣，年底旅遊交通也有新消息。Wings Air將於11月27日恢復Jember與峇里島之間的直飛航班，Badung則將在本週末舉辦大型創意經濟節。

## 🌦️ 11月24日峇里島天氣：多地仍有豪雨可能，南部海域浪高達2公尺

印尼氣象、氣候及地球物理局（BMKG）峇里島第三區氣象中心公布11月24日最新天氣預報，整體以小雨為主，但仍須留意部分地區可能出現中至大雨及雷電。

**11月24日全島天氣概況：**

| 項目 | 預報 |
| --- | --- |
| 天氣 | 小雨，局部可能較強 |
| 氣溫 | 20–33°C |
| 相對濕度 | 70–95% |
| 風向 | 東南至西南風 |
| 風速 | 4–31公里／小時 |
| 北部海域浪高 | 0.5–1公尺 |
| 南部海域浪高 | 0.5–2公尺 |

BMKG提醒，峇里島大部分地區仍有中至大雨及雷電的可能，尤其山區、河川周邊及容易積水的低窪地區，應留意突發性降雨。

**另外，還有一項容易被旅客忽略的警報：沿海高潮淹水（Rob）。**

BMKG第三區已發布11月23日至25日沿海高潮淹水預警。11月24日適逢滿月及月球近地點（Perigee），可能使部分沿海地區的最高潮位增加。

六個可能受影響的縣市及區域包括：

| 地區 | 可能受影響的沿海區域 |
| --- | --- |
| Badung巴東 | Kuta、Kuta Selatan、Kuta Utara、Mengwi |
| Gianyar吉安雅 | Blahbatuh、Gianyar、Sukawati |
| Jembrana珍布拉娜 | Jembrana、Melaya、Mendoyo、Negara、Pekutatan |
| Klungkung克隆孔 | Banjarangkan、Dawan、Klungkung、Nusa Penida |
| Denpasar登巴薩 | Denpasar Selatan、Denpasar Timur |
| Tabanan | Kediri、Kerambitan、Selemadeg、Selemadeg Barat、Selemadeg Timur、Tabanan |

這項警報不代表上述地區一定會發生淹水，也不代表海灘全面關閉，而是提醒沿海低窪地區、港口及海灘活動應留意潮汐變化。

**給旅客的提醒：**

- 住在Kuta、Seminyak、Sanur及Nusa Dua等沿海區域，可留意住宿周邊是否有積水。
- 前往海灘拍照或散步時，注意潮位及海浪變化。
- 前往Nusa Penida的旅客，除了確認船班，也應留意碼頭及沿岸狀況。
- 雨勢較大時，避免安排瀑布、山區及河谷活動。

## 🚨 峇里島一夜豪雨造成20處災情！Kuta、Legian及登巴薩道路淹水

11月22日下午至23日凌晨，峇里島多地遭遇強降雨，根據峇里島省災害管理局（BPBD）截至11月23日上午9時的統計，全島共有20處災害事件。

https://www.instagram.com/reel/DgD70siy50u/?utm_source=ig_web_copy_link&bqrl=NTc4MTIwNjQ2YQ==

降雨量相當驚人：

| 地區 | 24小時累積雨量 |
| --- | --- |
| Tampaksiring | 161毫米 |
| Karangasem | 149毫米 |
| Selemadeg Barat | 111毫米 |

其中Tampaksiring已達極端降雨等級。

20處災害事件分布如下：

- Denpasar：7處
- Badung：4處
- Tabanan：4處
- Jembrana：2處
- Karangasem：2處
- Bangli：1處

主要災情包括道路淹水、樹木倒塌、土石流及建築物受損。

**對遊客影響較直接的是Kuta及Legian。**

11月23日上午，Kuta及Legian部分道路出現積水，部分路段水深達成人小腿附近。Tukad Mati河道也因水量增加，出現大量塑膠垃圾及木材卡在橋下的情況。

當地清潔人員及相關單位已投入清理，部分積水逐漸消退，但仍有地點需要抽水及清除障礙物。

另外，當晚及凌晨的豪雨也造成兩起嚴重事故：

- Badung縣Mengwi一名女童跌入排水溝，遭急流沖走，於11月23日下午尋獲，已不幸身亡。
- Karangasem縣Sidemen一名65歲女性遭土石流掩埋，救援人員於11月23日上午尋獲遺體。

這兩起事故都與強降雨有關，也顯示雨季期間排水溝、河道及山坡周邊的危險性。

**給旅客的提醒：**

如果明天準備從機場前往Kuta、Legian或Seminyak，建議出發前確認道路狀況，並預留更多交通時間。

雨季在峇里島開車，最需要避免的不是下雨本身，而是低估積水、河水暴漲及山坡土石流的風險。遇到積水路段，不要冒險涉水通過。

## ✈️ Jember直飛峇里島航線11月27日恢復！Wings Air每週飛航兩班

印尼東爪哇Jember與峇里島之間的直飛航班即將恢復，對計畫結合東爪哇及峇里島旅行的旅客來說，是一項值得留意的交通消息。

根據Jember交通局11月23日公布的消息，Wings Air將從2026年11月27日起，重新營運Jember至峇里島的航線。

航班資料如下：

| 項目 | 資訊 |
| --- | --- |
| 航空公司 | Wings Air |
| 航線 | Jember（JBB）－Denpasar（DPS） |
| 開始日期 | 2026年11月27日 |
| 班次 | 每週一、週五 |
| 機型 | ATR 72-500／ATR 72-600 |
| 飛行時間 | 約1小時20分鐘 |

參考時刻：

- 峇里島飛往Jember：08:05 WITA出發
- Jember飛往峇里島：09:00 WIB出發

目前公布的起始票價為：

- Jember → 峇里島：IDR 640,000起
- 峇里島 → Jember：IDR 761,000起

實際票價會依出發日期及座位供應而變動。

這條航線過去曾於2025年12月開通，但因航空燃油成本上升，於2026年5月暫停營運，這次配合聖誕節及新年假期重新啟用。

對峇里島旅客而言，這也增加了安排東爪哇旅行的可能性。Jember周邊可以延伸探索Papuma Beach、Watu Ulo Beach及周邊自然景點。

如果已經在峇里島旅行，想順道前往東爪哇，未來可以多一個不必長途搭乘汽車及渡輪的選擇。

## 🏌️ Handara Golf & Resort連續兩年獲亞洲最佳環保高爾夫設施！Bedugul高原度假再受國際關注

位於峇里島Bedugul高原的Handara Golf & Resort Bali，再度獲得World Golf Awards 2026的Asia's Best Eco-Friendly Golf Facility獎項，連續兩年獲得相同肯定。

這項獎項肯定度假村在環境保護及永續經營方面的努力，今年也恰逢Handara成立50週年。

Handara表示，目前推動的環保措施包括：

- 節約及管理水資源
- 減少垃圾及一次性塑膠使用
- 推動Micro Farm及Farm to Table
- 使用在地農產品及供應商
- 加強與當地社區的合作

度假村也表示，約90%的員工及高爾夫球場球僮來自周邊地區，並與16家在地供應商合作。

Handara位於Bedugul高原，周邊氣候較涼爽，與峇里島南部海岸型度假村有明顯不同。

對喜歡高爾夫、山區度假及自然環境的旅客來說，這項消息也讓Handara再次受到國際旅遊市場關注。

不過，這是設施及永續經營方面的產業獎項，並不等同於住宿品質排名或價格保證，實際預訂仍應參考房型、設施及近期旅客評價。
