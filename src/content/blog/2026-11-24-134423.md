# **峇里島最新新聞｜11月25日：雨季豪雨警報、離島快艇加強檢查與外國人遣返**

峇里島雨季持續帶來天氣及交通方面的挑戰。BMKG最新預報指出，11月25日部分地區仍有中至大雨及雷電可能，Bedugul、金塔馬尼及Besakih等景點都需要留意天氣變化。

另外，隨著聖誕節及新年旅遊旺季接近，峇里島警方開始加強海上交通安全檢查，特別是往返努沙佩尼達的快艇。移民局也公布最新外國人遣返案件，而Sanur則有一場印度文化節正在舉行。

## **🌧️ BMKG預警11月25日部分地區大雨！金塔馬尼、Bedugul及Besakih留意雷雨**

印尼氣象、氣候及地球物理局（BMKG）峇里島第三區氣象中心於11月24日發布最新預警，預測11月24日至27日期間，峇里島部分地區可能出現中至大雨，並伴隨雷電。

**11月25日全島天氣概況：**

| 項目 | 預報 |
| --- | --- |
| 整體天氣 | 小雨，局部可能較強 |
| 氣溫 | 20–33°C |
| 相對濕度 | 70–98% |
| 風向 | 東南至西南風 |
| 風速 | 4–30公里／小時 |
| 北部海域浪高 | 0.25–1公尺 |
| 南部海域浪高 | 0.5–2.5公尺 |

BMKG針對不同時段發布的降雨警戒：

- **11月25日至26日上午8時：** Badung、Bangli、Buleleng、Karangasem及Tabanan可能出現中等降雨。
- **11月26日至27日上午8時：** Badung、Buleleng及Tabanan進入大雨警戒，Bangli、Denpasar、Karangasem、Gianyar及Klungkung則需留意中等降雨。

另外，BMKG特別點名11月25日以下旅遊地區可能出現降雨及雷電：

- Bedugul（貝都古）
- Kintamani（金塔馬尼）
- Besakih（母廟）

**對旅客的影響：**

如果明天安排金塔馬尼火山景觀、Bedugul湖區或Besakih母廟，建議保留行程彈性，避免在雷雨期間進行山區戶外活動。

南部海域浪高可能達2.5公尺，前往努沙佩尼達、努沙藍夢島的旅客，應在出發前確認快艇公司是否正常營運。

雨季並不代表整天都會下雨，但這幾天不建議把瀑布、山區及海上活動排得太緊密。

## **🚤 峇里島警方部署4艘巡邏船！努沙佩尼達快艇加強安全檢查**

隨著聖誕節及2027年新年旅遊旺季接近，峇里島警方海上警察單位（Ditpolairud Polda Bali）已啟動港口整合安全巡邏，部署4艘巡邏船，加強峇里島各海上交通入口的管理。

根據11月24日Bali Post報導，警方特別關注Badung海峽（Selat Badung），包括Sanur及Kusamba往返努沙佩尼達的快艇航線。

這次安全管理分為兩個層面：

**港口檢查**

警方與港務單位在各港口進行出航前檢查，主要確認：

- 船上乘客人數與乘客名冊是否一致。
- 是否有超載情況。
- 救生衣數量是否符合乘客人數。
- 滅火器及救生艇是否能正常使用。

如果船隻設備不符合安全要求，將不允許出航。

**海上巡邏**

4艘巡邏船將加強容易發生事故的航線監控，尤其是往返努沙佩尼達的快艇，避免船隻高速行駛、危險超車或切入大型船舶航道。

警方也將與BMKG、Basarnas印尼搜救單位及海軍合作，根據天氣與海況調整巡邏及安全管理。

**對旅客的影響：**

這項措施對搭乘Sanur至Nusa Penida、Kusamba至Nusa Penida快艇的旅客尤其重要。

建議：

- 選擇有正式營運及安全設備的快艇業者。
- 不要為了趕時間選擇超載船隻。
- 出發前確認救生衣及安全設備。
- 雨季期間不要只依賴船公司原定時刻表，應確認當日是否正常出航。

這次加強檢查並不代表離島航線全面停駛，而是希望在年底旺季到來前，降低海上交通事故風險。

## **🛂 峇里島移民局再遣返5名外國人！包括逾期居留及持訪問簽證經營刺青店**

峇里島Denpasar移民拘留中心（Rudenim Denpasar）於11月24日公布，近期共遣返5名違反印尼移民規定的外國人，國籍包括俄羅斯、葉門、印度及澳洲。

這批案件中，公開的違規情況包括：

| 國籍 | 違規情況 |
| --- | --- |
| 俄羅斯 | 逾期居留45天 |
| 印度 | 逾期居留187天 |
| 葉門 | 逾期居留64天 |
| 澳洲 | 持訪問簽證在Kuta經營刺青生意 |
| 澳洲 | 逾期居留787天，超過兩年 |

其中，持訪問簽證在Kuta經營刺青生意的澳洲籍人士，是這次案件中值得特別注意的案例。

移民局認為，持有訪問簽證不代表可以在峇里島從事未獲許可的商業活動，因此依法執行遣返。

另一名澳洲籍人士逾期居留787天，時間已超過兩年。

移民拘留中心負責人Teguh Mentalyadi表示，外國人在印尼必須遵守相同的移民規定，遣返程序須在完成行政手續及旅行文件準備後執行。

**給旅客及長期居留者的提醒：**

- VOA及eVOA必須在允許的停留期限內離境或依法延簽。
- 訪問簽證不等於工作許可。
- 即使是在峇里島經營小型商業活動，也應確認適用的簽證及工作許可。
- 如果計畫長期居留，不要等到簽證即將到期才處理延期。

一般觀光客不需要因為這類案件過度擔心，但簽證期限與實際活動是否符合許可範圍，確實是不能忽略的事情。
