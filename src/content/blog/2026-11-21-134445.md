# 峇里島最新新聞｜11月22日：雨季天氣、金塔馬尼道路坍塌與旅遊管理新政策

峇里島11月21日的最新消息，主要集中在雨季交通安全、旅遊承載量管理及海上觀光安全。BMKG預測11月22日部分地區仍有中至大雨及雷電風險，金塔馬尼一條替代道路也因先前豪雨坍塌，至今尚未修復。此外，峇里島政府開始研究未來國際遊客的合理承載量，住宿業者的合法執照問題也持續受到關注。

## **🌦️ BMKG預測11月22日局部降雨！南部海域浪高可能達2公尺**

印尼氣象、氣候及地球物理局（BMKG）峇里島第三區氣象中心公布11月22日天氣預報，整體預測以小雨為主，但東部、中部及西部部分地區仍須留意中至大雨及雷電。

**11月22日天氣概況：**

| 項目 | 預測 |
| --- | --- |
| 整體天氣 | 小雨 |
| 氣溫 | 20–34°C |
| 相對濕度 | 60–95% |
| 風向 | 東至南風 |
| 風速 | 4–37公里／小時 |
| 北部海域浪高 | 0.5–1.25公尺 |
| 南部海域浪高 | 0.75–2公尺 |

BMKG特別發布降雨提醒，峇里島東部、中部及西部部分地區可能出現中至大雨，並伴隨雷電。

海象方面，以下區域須留意2公尺或以上的浪高：

- 峇里島海峽南部
- 龍目海峽南部
- 巴東海峽（Selat Badung）
- 峇里島南部海域

**對旅客的影響：**

如果安排烏布、金塔馬尼、Bedugul等山區景點，建議留意午後降雨及道路狀況，避免在豪雨期間行經陡坡或容易發生落石的路段。

前往努沙佩尼達、努沙藍夢島及其他離島的旅客，應向船公司確認最新海況。尤其不要只看出發港口的天氣，目的地及航行路線的海況同樣重要。

這是局部天氣警報，並不代表全島景點都會關閉，實際情況仍需依照當地最新預報判斷。

## **🚧 前往金塔馬尼的一條替代道路坍塌！Jalan Pulasari Kawan至今尚未修復**

峇里島Bangli縣一條通往金塔馬尼（Kintamani）的替代道路，因11月初豪雨造成路面坍塌，目前仍處於完全中斷狀態。

根據11月20日detikBali報導，受影響路段為：

**Jalan Pulasari Kawan**

位置：Pulasari村、Tembuku區、Bangli縣。

這條道路在11月初受到豪雨影響，路面出現嚴重坍塌，導致整段道路無法通行。

11月20日，Bangli縣議會相關委員會實地視察後，要求地方政府優先安排修復工程，並進行技術評估，確認道路坍塌的原因及後續施工方案。

不過，這條路屬於往返金塔馬尼的其中一條替代道路，並不是所有前往金塔馬尼的道路都已中斷，其他替代路線仍可使用。

**給旅客的提醒：**

- 前往金塔馬尼觀賞巴杜爾火山及湖景，建議使用主要道路。
- 不要為了節省時間，隨意跟隨導航進入不熟悉的鄉間小路。
- 包車旅客可事先請司機確認當天道路狀況。
- 如果遇到豪雨，應避免行經山坡、坍方及積水路段。

目前尚未公布這條道路的確切修復完成日期。

## **🌍 峇里島研究國際遊客承載量！未來可能制定入島管理規範**

峇里島省長Wayan Koster於11月19日表示，省政府將研究峇里島能夠長期承受的國際遊客數量，並考慮制定相關地方規範，讓觀光發展與環境、基礎設施及文化保存取得平衡。

這項研究主要評估：

- 峇里島自然環境的承載能力
- 道路、交通及公共設施容量
- 水資源及垃圾處理能力
- 峇里島傳統文化與居民生活受到的影響

Koster表示，未來將依據研究結果，準備相關地方自治法規（Perda），作為觀光客管理的政策依據。

**但要特別注意，目前並沒有正式公布外國遊客每日入境配額，也沒有宣布新的入境限制或實施日期。** 現階段仍是研究及政策準備階段，不能解讀為外國旅客即將無法自由前往峇里島。

另一方面，峇里島政府也持續要求線上訂房平台（OTA）停止銷售沒有合法營業執照的住宿。

省長表示，2025至2026年間約有5,000家Villa業者提出執照申請。政府希望透過住宿業者合法化，改善市場競爭及住宿管理。

對旅客來說，這項政策有一個比較實際的影響：未來透過Agoda、Booking.com、Airbnb等平台搜尋住宿時，沒有符合當地營業許可要求的住宿，可能無法繼續在平台上銷售。

這並不代表峇里島禁止Villa住宿，也不是所有私人Villa都違法。旅客預訂時，建議選擇資料清楚、合法經營的住宿，尤其是長期住宿或整棟Villa預訂，更應確認業者的營業資訊。

峇里島未來的觀光政策方向，顯然正逐漸從單純追求遊客數量，轉向環境承載力、住宿合法化及旅遊品質管理。

## **🚢 Benoa郵輪碼頭加強安全檢查！提前準備聖誕及新年旅遊旺季**

峇里島登巴薩的Benoa港口，近期開始加強旅客及郵輪相關安全管理，為2026年聖誕節及2027年新年旅遊旺季做準備。

根據11月20日Bali Post報導，Denpasar警方及Benoa港口警察單位已增加碼頭巡邏，並與港務、海關、Pelindo及檢疫單位加強合作。

主要管理項目包括：

- 郵輪及客船進出港監控
- 旅客及行李檢查
- 貨物及物流管理
- 防止毒品、危險物品及違禁品進入
- 加強碼頭周邊治安巡邏

Benoa是峇里島重要的海上旅遊入口，除了國內客船，也接待國際郵輪旅客。

Pelindo也持續改善郵輪服務設施，東側郵輪碼頭已從350公尺延長至500公尺，具備同時停靠兩艘大型郵輪的能力。

目前已有76艘郵輪登記計畫於2026年停靠Benoa，顯示峇里島郵輪旅遊市場仍在發展。

對一般自由行旅客來說，這項措施不會直接改變機場入境程序；但如果搭乘郵輪抵達峇里島，近期可能會遇到較密集的港口安全檢查。

目前沒有公布新的旅客入港限制或額外收費規定。

## **🏖️ Kuta Selatan海灘持續加強警察巡邏！提醒遊客勿忽略海況及安全標誌**

峇里島南部的南庫塔地區，包括部分懸崖海灘及熱門海岸景點，近期持續加強海上及陸地巡邏。

根據Bali Post及NusaBali相關報導，Denpasar警方海上警察單位（Satpolairud）於11月18日繼續在Kuta Selatan海域及海灘執行巡邏工作。

巡邏方式包括：

- 使用警用船隻巡查海域
- 在容易發生事故的海岸區域進行陸上巡邏
- 觀察遊客、漁民及海上活動狀況
- 遇到危險情況時進行勸導及必要的安全處置

警方特別關注海上事故、遊客危險活動及海灘公共秩序問題。

Kuta Selatan部分海灘地形特殊，尤其是位於懸崖下方的海灘，緊急救援及撤離可能比一般沙灘困難。

警方提醒遊客：

- 遵守海灘上的安全標誌及禁止游泳指示。
- 不要在海浪或海流明顯增強時勉強下水。
- 不要擅自進入限制區域。
- 前往懸崖海灘時，注意上下坡及回程時間。

這次巡邏並不是宣布Kuta Selatan海灘全面禁止游泳，也沒有公布新的統一關閉措施，而是持續性的安全監控。

特別是在雨季及海況不穩定期間，旅客不要只看海灘是否漂亮，也要注意現場海浪、離岸流及救援條件。
